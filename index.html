§1 Классификация неорганических соединений

Все вещества в химии делятся на простые и сложные. Простые состоят из атомов одного элемента (O₂, Fe, S), сложные — из атомов разных элементов (H₂O, NaCl, H₂SO₄).

Среди сложных неорганических веществ выделяют четыре важнейших класса: оксиды, основания, кислоты, соли. Каждый класс имеет свой состав, строение и химические свойства.

Оксиды Сложные вещества, состоящие из двух элементов, один из которых — кислород в степени окисления −2.
Примеры: Na₂O, CaO, Al₂O₃, CO₂, SO₃, Fe₂O₃.

Оксиды делятся на:

  • Основные — оксиды металлов со степенью окисления +1, +2 (Na₂O, CaO, MgO, CuO). Реагируют с кислотами и кислотными оксидами.
  • Кислотные — оксиды неметаллов и металлов с высокой степенью окисления (CO₂, SO₃, P₂O₅, Mn₂O₇). Реагируют с основаниями и основными оксидами.
  • Амфотерные — проявляют и кислотные, и основные свойства (Al₂O₃, ZnO, BeO, Cr₂O₃).
  • Несолеобразующие — не образуют солей (CO, NO, N₂O, SiO).
Основания Сложные вещества, состоящие из иона металла и одной или нескольких гидроксид-групп OH⁻.
Общая формула: Me(OH)ₙ, где n — валентность металла.
Примеры: NaOH, KOH, Ca(OH)₂, Fe(OH)₃.

Основания делятся на:

  • Растворимые (щёлочи): NaOH, KOH, LiOH, Ca(OH)₂, Ba(OH)₂.
  • Нерастворимые: Cu(OH)₂, Fe(OH)₃, Al(OH)₃, Mg(OH)₂.
  • Амфотерные гидроксиды: Zn(OH)₂, Al(OH)₃, Be(OH)₂, Cr(OH)₃.
Кислоты Сложные вещества, состоящие из атомов водорода, способных замещаться металлом, и кислотного остатка.
Примеры: HCl, H₂SO₄, HNO₃, H₃PO₄, CH₃COOH.

Кислоты классифицируют:

  • По числу атомов H (основности): одноосновные (HCl, HNO₃), двухосновные (H₂SO₄, H₂S), трёхосновные (H₃PO₄).
  • По наличию кислорода: кислородсодержащие (H₂SO₄, HNO₃) и бескислородные (HCl, H₂S).
  • По силе: сильные (HCl, H₂SO₄, HNO₃), средние (H₃PO₄, HF), слабые (H₂CO₃, H₂S, CH₃COOH).
Соли Сложные вещества, состоящие из иона металла (или NH₄⁺) и аниона кислотного остатка.
Примеры: NaCl, K₂SO₄, CaCO₃, Cu(NO₃)₂.

Соли делятся на:

  • Средние (нормальные): NaCl, K₂SO₄, Ca₃(PO₄)₂.
  • Кислые: NaHCO₃, KHSO₄, Ca(H₂PO₄)₂.
  • Основные: Cu₂(OH)₂CO₃ (малахит), Mg(OH)Cl.
  • Двойные: KAl(SO₄)₂.
  • Комплексные: K₄[Fe(CN)₆], Na₃[Al(OH)₆].

§2 Классификация химических реакций

Химические реакции классифицируют по нескольким признакам. Рассмотрим каждый.

1. По числу и составу исходных веществ и продуктов реакции:

  • Реакции соединения — из нескольких веществ образуется одно.
    2H₂ + O₂ → 2H₂O
  • Реакции разложения — из одного вещества образуется несколько.
    2H₂O₂ → 2H₂O + O₂↑
  • Реакции замещения — атомы простого вещества замещают атомы в сложном.
    Fe + CuSO₄ → FeSO₄ + Cu↓
  • Реакции обмена — два сложных вещества обмениваются составными частями.
    NaOH + HCl → NaCl + H₂O

2. По тепловому эффекту:

  • Экзотермические — идут с выделением теплоты (+Q).
    C + O₂ → CO₂ + Q
  • Эндотермические — идут с поглощением теплоты (−Q).
    CaCO₃ → CaO + CO₂ − Q

3. По обратимости:

  • Необратимые — идут до полного расходования одного из исходных веществ. Обозначаются «→».
    BaCl₂ + H₂SO₄ → BaSO₄↓ + 2HCl
  • Обратимые — идут одновременно в прямом и обратном направлениях. Обозначаются «⇄».
    N₂ + 3H₂ ⇄ 2NH₃

4. По изменению степеней окисления:

  • Окислительно-восстановительные (ОВР) — степени окисления элементов изменяются.
    Zn⁰ + Cu²⁺SO₄ → Zn²⁺SO₄ + Cu⁰
  • Не ОВР — степени окисления не изменяются.
    NaOH + HCl → NaCl + H₂O

5. По агрегатному состоянию:

  • Гомогенные — все вещества в одном агрегатном состоянии.
  • Гетерогенные — вещества в разных состояниях.

6. По использованию катализатора:

  • Каталитические — идут в присутствии катализатора.
    N₂ + 3H₂ ⇄ 2NH₃ (кат. Fe)
  • Некаталитические — без катализатора.

7. По направлению:

  • Прямые — идут в направлении образования продуктов.
  • Обратные — идут в направлении образования исходных веществ.

§3 Скорость химических реакций. Катализ

Реакции идут с разной скоростью: одни мгновенно (взрыв), другие — годами (ржавление железа). Для управления реакциями нужно уметь её измерять и изменять.

Скорость химической реакции Это изменение концентрации одного из реагирующих веществ за единицу времени.
Формула: υ = ΔC / Δt
где ΔC — изменение концентрации (моль/л), Δt — промежуток времени (с).

Единицы измерения: моль/(л·с).

Факторы, влияющие на скорость реакции:

1. Природа реагирующих веществ. Реакции с участием активных веществ (например, щелочных металлов) идут быстрее, чем реакции тех же классов с малоактивными.

2. Концентрация. Чем выше концентрация, тем чаще сталкиваются частицы и тем быстрее идёт реакция. Это выражено в законе действующих масс:

Для реакции aA + bB → продукты: υ = k·[A]ᵃ·[B]ᵇ

где k — константа скорости, [A] и [B] — концентрации реагирующих веществ.

3. Температура. При повышении температуры на каждые 10 °C скорость реакции возрастает в 2–4 раза (правило Вант-Гоффа):

υ₂ / υ₁ = γ^(Δt / 10)

где γ — температурный коэффициент (обычно 2–4).

4. Площадь поверхности соприкосновения. Для гетерогенных реакций чем больше площадь поверхности (измельчение, перемешивание), тем выше скорость.

5. Катализатор. Вещество, ускоряющее реакцию, но не расходующееся в ней.

6. Давление. Для газов — чем выше давление, тем выше концентрация и скорость.

7. Свет, электрический ток, излучение. Некоторые реакции идут только под действием этих факторов (фотосинтез, электролиз).

Катализ Явление изменения скорости реакции под действием катализатора.
Катализатор — вещество, ускоряющее реакцию, но не расходующееся.
Ингибитор — вещество, замедляющее реакцию.

Виды катализа:

  • Гомогенный — катализатор и реагенты в одном агрегатном состоянии.
  • Гетерогенный — катализатор и реагенты в разных состояниях (чаще всего твёрдый катализатор + газ или раствор).
  • Ферментативный — с участием биологических катализаторов (ферментов).

Механизм действия катализатора: катализатор образует с реагирующими веществами промежуточные соединения, которые затем распадаются с образованием продуктов. Сам катализатор при этом возвращается в исходное состояние.

Важнейшие катализаторы в промышленности:

Пример 3
Задание. Как изменится скорость реакции 2SO₂ + O₂ → 2SO₃, если увеличить давление в 3 раза?
Решение.
Объём газов уменьшается в 3 раза → концентрация увеличивается в 3 раза.
υ₁ = k·[SO₂]²·[O₂].
υ₂ = k·(3[SO₂])²·(3[O₂]) = k·9[SO₂]²·3[O₂] = 27·υ₁.
Ответ: скорость увеличится в 27 раз.
Пример 4
Задание. Как изменится скорость реакции при повышении температуры с 20 °C до 40 °C, если γ = 3?
Решение. Δt = 20 °C. υ₂/υ₁ = 3^(20/10) = 3² = 9.
Ответ: скорость увеличится в 9 раз.

§1 Электролитическая диссоциация

Многие вещества, попадая в воду, начинают проводить электрический ток — их растворы становятся проводниками второго рода. Это возможно только потому, что в растворе появляются свободно движущиеся заряженные частицы — ионы.

Электролитическая диссоциация Это процесс распада молекул электролита на ионы (катионы и анионы) при растворении в воде или при расплавлении.

Примеры:

NaCl → Na⁺ + Cl⁻ (в воде)
KOH → K⁺ + OH⁻ (в воде)
HNO₃ → H⁺ + NO₃⁻ (в воде)

Электролиты — вещества, распадающиеся на ионы. К ним относятся:

  • Растворимые соли — NaCl, KNO₃, CuSO₄, Na₂CO₃, NH₄Cl.
  • Растворимые основания (щёлочи) — NaOH, KOH, LiOH, Ca(OH)₂, Ba(OH)₂.
  • Кислоты — HCl, H₂SO₄, HNO₃, H₃PO₄, CH₃COOH.

Неэлектролиты — вещества, не распадающиеся на ионы:

  • Органика — сахар (C₁₂H₂₂O₁₁), глюкоза (C₆H₁₂O₆), спирт (C₂H₅OH), ацетон.
  • Простые вещества — O₂, H₂, N₂, Cl₂.
  • Оксиды — CO₂, SiO₂, SO₂, CaO.
  • Нерастворимые соли и основания — CaCO₃, BaSO₄, Cu(OH)₂, Fe(OH)₃.

💡 Растворы неэлектролитов не проводят ток, потому что в них нет свободных ионов — молекулы остаются нейтральными.

Механизм диссоциации зависит от типа связи:

А. Вещества с ионной связью (соли, щёлочи). Молекулы воды притягиваются к ионам кристаллической решётки: положительные концы молекул воды (водороды) ориентируются к анионам, отрицательные (кислороды) — к катионам. Притяжение молекул воды становится сильнее, чем притяжение ионов друг к другу — решётка разрушается, и каждый ион выходит в раствор вместе с оболочкой воды.

Б. Вещества с ковалентной полярной связью (кислоты). Молекулы воды подходят к полярной молекуле, ориентируются к её концам и «разрывают» связь. Общая электронная пара смещается к более электроотрицательному атому — образуются ионы, которые сразу гидратируются.

💡 В расплавах диссоциация происходит потому, что при нагревании кристаллическая решётка разрушается. Именно поэтому расплавленный NaCl проводит ток, а твёрдый — нет.

§2 Основные положения теории электролитической диссоциации

Теория электролитической диссоциации (ТЭД) была сформулирована шведским учёным Сванте Аррениусом в 1887 году.

Основные положения ТЭД:

  • 1. Электролиты при растворении в воде распадаются на ионы — катионы и анионы.
    HCl → H⁺ + Cl⁻
    Катион — положительно заряженный ион (H⁺, Na⁺, Cu²⁺, NH₄⁺).
    Анион — отрицательно заряженный ион (Cl⁻, OH⁻, SO₄²⁻, PO₄³⁻).
  • 2. Причиной диссоциации является взаимодействие молекул электролита с молекулами воды (гидратация). Молекулы воды полярны: атом кислорода несёт частичный отрицательный заряд, атомы водорода — частичный положительный.
  • 3. Ионы в растворе взаимодействуют с молекулами воды и образуют гидратированные ионы. Каждый ион окружён «шубой» из молекул воды.
  • 4. Диссоциация — обратимый процесс. Наряду с распадом молекул на ионы идёт обратный процесс — ассоциация.
    CH₃COOH ⇄ CH₃COO⁻ + H⁺
  • 5. Сильные электролиты диссоциируют полностью (необратимо), слабые — частично (обратимо).
  • 6. Химические свойства растворов электролитов определяются свойствами тех ионов, которые образуются при диссоциации.

Степень диссоциации (α) — отношение числа молекул, распавшихся на ионы, к общему числу растворённых молекул:

α = N(распавшихся) / N(общих) × 100%

Классификация электролитов по степени диссоциации:

КатегорияСтепень αПримеры
Сильныеα > 30%HCl, HBr, HI, HNO₃, H₂SO₄, NaOH, KOH, Ba(OH)₂, все растворимые соли
Средние3% < α < 30%H₃PO₄, HF, H₂SO₃, HNO₂, Ca(OH)₂
Слабыеα < 3%CH₃COOH, H₂CO₃, H₂S, H₂SiO₃, NH₄OH, вода

От чего зависит α:

  • От природы электролита — чем полярнее связь, тем легче диссоциация.
  • От температуры — при нагревании α увеличивается.
  • От концентрации — при разбавлении α увеличивается.
  • От природы растворителя — в полярных растворителях диссоциация идёт лучше.

Правила записи уравнений диссоциации:

  • 1. Формулу электролита пишем слева, ионы — справа.
  • 2. Число атомов каждого элемента слева и справа должно совпадать.
  • 3. Сумма зарядов ионов справа должна быть равна нулю.
  • 4. Многоосновные кислоты и многокислотные основания диссоциируют ступенчато.

Пример 1. Соль.

Al₂(SO₄)₃ → 2Al³⁺ + 3SO₄²⁻

Проверка: 2·(+3) + 3·(−2) = +6 − 6 = 0. ✔

Пример 2. Ступенчатая диссоциация H₃PO₄:

1-я: H₃PO₄ ⇄ H⁺ + H₂PO₄⁻
2-я: H₂PO₄⁻ ⇄ H⁺ + HPO₄²⁻
3-я: HPO₄²⁻ ⇄ H⁺ + PO₄³⁻

💡 Каждая следующая ступень идёт слабее предыдущей.

Пример 3
Задание. В растворе из 200 молекул уксусной кислоты распалось 6 молекул. Найдите α.
Решение. α = 6 / 200 × 100% = 3%.
Ответ: α = 3% — уксусная кислота относится к слабым электролитам.

§3 Химические свойства кислот как электролитов

Кислоты — электролиты, которые при диссоциации в водном растворе образуют только катионы водорода H⁺ (точнее — ионы гидроксония H₃O⁺) и анионы кислотного остатка.

Примеры диссоциации:

HCl → H⁺ + Cl⁻
H₂SO₄ → 2H⁺ + SO₄²⁻
HNO₃ → H⁺ + NO₃⁻

Классификация кислот:

  • По содержанию кислорода: кислородсодержащие (H₂SO₄, HNO₃) и бескислородные (HCl, H₂S).
  • По основности: одноосновные (HCl, HNO₃), двухосновные (H₂SO₄, H₂CO₃), трёхосновные (H₃PO₄).
  • По силе: сильные (HCl, H₂SO₄, HNO₃), средние (H₃PO₄, HF), слабые (H₂CO₃, CH₃COOH).

§5 Химические свойства солей как электролитов

Соли — электролиты, которые при диссоциации образуют катионы металла (или ион аммония NH₄⁺) и анионы кислотного остатка.

Примеры диссоциации:

NaCl → Na⁺ + Cl⁻
Al₂(SO₄)₃ → 2Al³⁺ + 3SO₄²⁻

Классификация солей:

  • Средние: NaCl, K₂SO₄, Ca(NO₃)₂.
  • Кислые: NaHCO₃, KHSO₄, Ca(H₂PO₄)₂.
  • Основные: Cu₂(OH)₂CO₃, Mg(OH)Cl.
  • Двойные: KAl(SO₄)₂.
  • Комплексные: K₄[Fe(CN)₆], Na₃[Al(OH)₆].

Химические свойства солей:

1. С металлами (более активный металл вытесняет менее активный):

§6 Гидролиз солей
Гидролиз солей Обменная реакция между ионами соли и молекулами воды, приводящая к образованию слабого электролита и изменению кислотности среды.

Вода — слабый электролит:

H₂O ⇄ H⁺ + OH⁻

Когда в растворе есть ионы, способные связать H⁺ или OH⁻ в слабый электролит, они «забирают» эти ионы у воды, и равновесие смещается — pH меняется.

Гидролизуются соли, образованные:

  • Слабой кислотой и сильным основанием → среда щелочная
  • Сильной кислотой и слабым основанием → среда кислая
  • Слабой кислотой и слабым основанием → среда зависит от силы

Не гидролизуются: соли сильной кислоты и сильного основания (NaCl, KNO₃, BaSO₄).

Четыре типа солей:

ТипКислотаОснованиеГидролизpHПример
1СильнаяСильноеНе гидролизуется= 7NaCl, KNO₃
2СлабаяСильноеПо аниону> 7Na₂CO₃, CH₃COONa
3СильнаяСлабоеПо катиону< 7NH₄Cl, CuCl₂
4СлабаяСлабоеПо катиону и анионуЗависитCH₃COONH₄

Гидролиз по аниону (тип 2):

CO₃²⁻ + H₂O ⇄ HCO₃⁻ + OH⁻ (щелочная среда)
Na₂CO₃ + H₂O ⇄ NaHCO₃ + NaOH

Гидролиз по катиону (тип 3):

Cu²⁺ + H₂O ⇄ CuOH⁺ + H⁺ (кислая среда)
CuCl₂ + H₂O ⇄ CuOHCl + HCl

Совместный гидролиз (тип 4):

CH₃COO⁻ + NH₄⁺ + H₂O ⇄ CH₃COOH + NH₄OH

Правила:

  • Усиливается при нагревании и разбавлении.
  • Подавляется добавлением кислоты (по аниону) или щёлочи (по катиону).
  • Необратимый гидролиз — если образуется и слабая кислота, и слабое основание, и они выводятся из реакции (осадок или газ).
Al₂S₃ + 6H₂O → 2Al(OH)₃↓ + 3H₂S↑
Пример
Задание. Определите среду растворов: NaCl, Na₂CO₃, NH₄Cl.
Решение.
— NaCl — соль сильной кислоты (HCl) и сильного основания (NaOH) → не гидролизуется, pH = 7.
— Na₂CO₃ — соль слабой кислоты (H₂CO₃) и сильного основания (NaOH) → гидролиз по аниону, среда щелочная, pH > 7.
— NH₄Cl — соль сильной кислоты (HCl) и слабого основания (NH₄OH) → гидролиз по катиону, среда кислая, pH < 7.

§1 Общая характеристика неметаллов

Из 118 известных химических элементов около 90 — металлы, а остальные — неметаллы. Неметаллы расположены в правой верхней части периодической системы (кроме водорода и гелия, которые стоят в IA и VIIIA группах).

Неметаллы Химические элементы, атомы которых преимущественно принимают электроны, образуя отрицательные ионы. В отличие от металлов, у неметаллов на внешнем энергетическом уровне 4–7 электронов (у водорода и бора — 1 и 3).

Положение в ПСХЭ:

  • VIIA группа: F, Cl, Br, I, At — галогены.
  • VIA группа: O, S, Se, Te — халькогены.
  • VA группа: N, P, As, Sb — пниктогены.
  • IVA группа: C, Si, Ge, Sn, Pb (C и Si — типичные неметаллы).
  • IIIA группа: B — неметалл, остальные — металлы.
  • IA группа: H — неметалл, остальные — щелочные металлы.
  • VIIIA группа: He, Ne, Ar, Kr, Xe, Rn — благородные (инертные) газы.

Строение атомов неметаллов:

  • На внешнем уровне 4–7 электронов (у H — 1, у B — 3).
  • Радиусы атомов меньше, чем у металлов того же периода.
  • Обладают высоким значением электроотрицательности.
  • Стремятся принять электроны до 8 (или 2, как гелий).

Физические свойства неметаллов:

  • Твёрдые, жидкие (Br₂) и газообразные (H₂, O₂, N₂, Cl₂).
  • Плохо проводят тепло и ток (исключение — графит).
  • Не обладают металлическим блеском (кроме кремния и графита).
  • Хрупкие.
  • Разные температуры плавления: от −210 °C (N₂) до 3800 °C (графит).

Химические свойства неметаллов:

  • Реагируют с металлами — образуют оксиды, сульфиды, галогениды:
    2Na + Cl₂ → 2NaCl
  • Реагируют с водородом — образуют летучие водородные соединения:
    H₂ + Cl₂ → 2HCl
  • Реагируют с кислородом — образуют кислотные оксиды:
    S + O₂ → SO₂
  • Реагируют друг с другом:
    2P + 5Cl₂ → 2PCl₅
Электроотрицательность Способность атома притягивать к себе электроны в химической связи. Ряд ЭО: F > O > N ≈ Cl > Br > I > S > C > P > H > металлы.

💡 Окислительные свойства неметаллов усиливаются к фтору (F самый сильный окислитель), а восстановительные — к водороду и углероду.

Пример
Задание. Расположите неметаллы F, O, N, Cl, S, C в порядке усиления окислительных свойств.
Решение. По значениям электроотрицательности и положению в ПСХЭ: C < S < N < Cl < O < F.
Ответ: C < S < N < Cl < O < F.

§2 Общая характеристика элементов VIIA группы — галогенов

Галогены (от греч. «рождающие соль») — элементы главной подгруппы VII группы: фтор F, хлор Cl, бром Br, йод I и радиоактивный астат At.

Галогены Элементы VIIA группы, на внешнем энергетическом уровне которых 7 электронов. До завершения уровня им не хватает 1 электрона, поэтому они — сильные окислители.

Строение атомов галогенов:

ЭлементСимволСтроение уровняРадиусЭО
ФторF2s²2p⁵самый малый4,0
ХлорCl3s²3p⁵малый3,0
БромBr4s²4p⁵средний2,8
ЙодI5s²5p⁵большой2,5

Закономерности сверху вниз:

  • Радиус атома увеличивается.
  • Электроотрицательность уменьшается.
  • Окислительные свойства ослабевают.
  • Температуры плавления и кипения увеличиваются.
  • Агрегатное состояние: газ → газ → жидкость → твёрдое.

Физические свойства простых веществ:

ВеществоЦветАгрегатное состояние
F₂бледно-жёлтыйгаз
Cl₂жёлто-зелёныйгаз
Br₂тёмно-бурыйжидкость
I₂тёмно-фиолетовыйтвёрдое (возгоняется)

Химические свойства галогенов:

1. С металлами — образуют галогениды:

2Na + Cl₂ → 2NaCl
2Fe + 3Cl₂ → 2FeCl₃

2. С водородом — образуют галогеноводороды:

H₂ + Cl₂ → 2HCl
H₂ + F₂ → 2HF (со взрывом)

3. С водой (кроме F₂):

Cl₂ + H₂O ⇄ HCl + HClO

4. С щелочами:

Cl₂ + 2NaOH → NaCl + NaClO + H₂O

Вытеснение менее активного галогена более активным:

Cl₂ + 2KBr → 2KCl + Br₂
Cl₂ + 2KI → 2KCl + I₂

💡 Ряд активности: F₂ > Cl₂ > Br₂ > I₂. Более активный галоген вытесняет менее активный из его соединений.

Пример

Решение.
а) 2Na + Cl₂ → 2NaCl
б) H₂ + Cl₂ → 2HCl
в) Cl₂ + 2KI → 2KCl + I₂

§3 Соединения галогенов

Важнейшие соединения галогенов: галогеноводороды (HF, HCl, HBr, HI), их водные растворы (кислоты) и соли (галогениды).

Галогеноводороды: бесцветные газы с резким запахом, хорошо растворимы в воде. Их растворы — кислоты.

СоединениеНазваниеСила кислотыСоль
HFПлавиковая (фтороводородная)слабаяфториды
HClСоляная (хлороводородная)сильнаяхлориды
HBrБромоводороднаясильнаябромиды
HIИодоводороднаясильнаяиодиды

Соли галогеноводородов — галогениды:

  • NaCl — поваренная соль, галит.
  • KCl — сильвин, калийное удобрение.
  • CaF₂ — флюорит (плавиковый шпат).
  • KI — иодид калия, применяется в медицине.
  • AgCl, AgBr, AgI — нерастворимые осадки (используются в фотографии).

Качественные реакции на галогенид-ионы:

NaCl + AgNO₃ → AgCl↓ (белый) + NaNO₃
NaBr + AgNO₃ → AgBr↓ (бледно-жёлтый) + NaNO₃
NaI + AgNO₃ → AgI↓ (жёлтый) + NaNO₃

💡 Осадки AgCl, AgBr, AgI нерастворимы в воде и в разбавленной азотной кислоте. Это используется для обнаружения галогенидов.

Применение галогенов и их соединений:

  • F₂ — получение фреонов, тефлона.
  • Cl₂ — обеззараживание воды, получение HCl, отбеливание тканей.
  • Br₂ — производство лекарств, красителей.
  • I₂ — спиртовой раствор (йод) — антисептик.
  • NaF — добавка в зубные пасты.
  • AgBr — фотоматериалы.
Пример
Задание. Как отличить растворы NaCl, NaBr, NaI друг от друга?
Решение. Добавить к каждому раствору AgNO₃.
— NaCl → AgCl↓ белый творожистый
— NaBr → AgBr↓ бледно-жёлтый
— NaI → AgI↓ жёлтый

§4 Изучение свойств соляной кислоты

Соляная кислота HCl — водный раствор хлороводорода. Это сильная одноосновная кислота, одна из важнейших в промышленности и в лаборатории.

Физические свойства:

  • Бесцветная жидкость с резким запахом.
  • Концентрированная кислота «дымит» на воздухе.
  • Хорошо растворяется в воде (до 40 % HCl).
  • Входит в состав желудочного сока (0,3 % HCl).

Химические свойства соляной кислоты (все свойства кислот):

1. Диссоциация:

HCl → H⁺ + Cl⁻

2. С металлами до H₂:

Zn + 2HCl → ZnCl₂ + H₂↑
Fe + 2HCl → FeCl₂ + H₂↑

3. С основными оксидами:

CuO + 2HCl → CuCl₂ + H₂O

4. С основаниями:

NaOH + HCl → NaCl + H₂O

5. С солями (если образуется осадок или газ):

AgNO₃ + HCl → AgCl↓ + HNO₃
Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑

Качественная реакция на Cl⁻: с AgNO₃ — белый творожистый осадок AgCl, нерастворимый в HNO₃.

Применение соляной кислоты:

  • Травление металлов перед пайкой и покрытием.
  • Получение хлоридов, хлора, лекарств.
  • Регулирование pH в промышленности.
  • В медицине — при недостатке HCl в желудке.
  • В пищевой промышленности (E507).

Лабораторная работа «Изучение свойств соляной кислоты»:

  1. Налейте в 4 пробирки немного HCl.
  2. Добавьте в 1-ю — Zn, во 2-ю — CuO, в 3-ю — NaOH, в 4-ю — Na₂CO₃.
  3. Что наблюдаете в каждой пробирке?
  4. Напишите уравнения реакций.

⚠ Техника безопасности: соляная кислота — едкое вещество. Работать в перчатках и очках, при попадании на кожу — промыть водой.

Пример
Задание. Как с помощью HCl распознать карбонат натрия среди других солей?
Решение. Добавить к раствору HCl — при наличии карбоната выделяется газ CO₂ (вскипание).
Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑

§5 Общая характеристика элементов VIA группы. Халькогены

Халькогены (от греч. «рождающие руду») — элементы главной подгруппы VI группы: кислород O, сера S, селен Se, теллур Te и радиоактивный полоний Po.

Халькогены Элементы VIA группы, на внешнем энергетическом уровне которых 6 электронов (ns²np⁴). До завершения уровня им не хватает 2 электронов.

Строение атомов:

ЭлементСимволСтроениеЭОСтепени окисления
КислородO2s²2p⁴3,5−2, −1, 0
СераS3s²3p⁴2,5−2, 0, +4, +6
СеленSe4s²4p⁴2,4−2, 0, +4, +6
ТеллурTe5s²5p⁴2,1−2, 0, +4, +6

Закономерности сверху вниз:

  • Радиус атома увеличивается.
  • Электроотрицательность уменьшается.
  • Окислительные свойства ослабевают.
  • Неметаллические свойства уменьшаются (Te уже амфотерный).

Кислород — самый распространённый элемент на Земле (49 % массы земной коры). Газ O₂ — бесцветный, без запаха, поддерживает горение и дыхание.

Сера — твёрдое жёлтое кристаллическое вещество. В природе встречается в самородном виде, а также в виде сульфидов (FeS₂, PbS, ZnS) и сульфатов (CaSO₄·2H₂O, Na₂SO₄).

Общее с водородом: образуют летучие соединения H₂O, H₂S, H₂Se, H₂Te. Их устойчивость уменьшается сверху вниз (H₂O самая устойчивая).

Общее с кислородом: образуют оксиды SO₂, SO₃, SeO₂, TeO₂. Для серы наиболее важны SO₂ (сернистый газ) и SO₃ (серный ангидрид).

Пример
Задание. Сравните строение атомов O и S. Чем они отличаются?
Решение. У обоих на внешнем уровне 6 электронов (ns²np⁴). Различие — в числе энергетических уровней: у O — 2, у S — 3. Это объясняет, почему S имеет больший радиус и меньшую ЭО, но может проявлять больше степеней окисления (+4, +6).

§6 Сера, сероводород и сульфиды

Сера — жёлтое кристаллическое вещество, нерастворимое в воде, но растворимое в сероуглероде CS₂. Образует несколько аллотропных модификаций: ромбическая (устойчивая), моноклинная, пластическая.

Химические свойства серы:

1. Реакции с металлами — образует сульфиды (S — окислитель):

Fe + S → FeS
2Na + S → Na₂S

2. Реакция с водородом:

H₂ + S → H₂S

3. Реакция с кислородом (S — восстановитель):

S + O₂ → SO₂

4. Реакция с другими неметаллами:

2P + 3S → P₂S₃

Сероводород H₂S — бесцветный газ с запахом тухлых яиц, очень ядовит. Раствор H₂S в воде — слабая двухосновная кислота:

H₂S ⇄ H⁺ + HS⁻
HS⁻ ⇄ H⁺ + S²⁻

Химические свойства H₂S:

  • Кислотные: реагирует с основаниями и оксидами металлов:
    H₂S + 2NaOH → Na₂S + 2H₂O
  • Восстановительные: горит с образованием SO₂ или S:
    2H₂S + 3O₂ → 2SO₂ + 2H₂O (избыток O₂)
  • С солями — образует нерастворимые сульфиды:
    H₂S + CuSO₄ → CuS↓ + H₂SO₄

Сульфиды — соли сероводородной кислоты. Многие нерастворимы и имеют характерную окраску:

СульфидЦвет
ZnSбелый
FeSчёрный
CuSчёрный
PbSчёрный
HgS (киноварь)красный
CdSжёлтый

💡 Качественная реакция на сульфид-ион S²⁻: с ионами Pb²⁺ образуется чёрный осадок PbS; с Cd²⁺ — жёлтый CdS.

Пример
Задание. Напишите уравнения: а) Fe + S; б) H₂S + NaOH (избыток); в) CuSO₄ + H₂S.
Решение.
а) Fe + S → FeS
б) H₂S + 2NaOH → Na₂S + 2H₂O
в) CuSO₄ + H₂S → CuS↓ + H₂SO₄

§7 Кислородные соединения серы

Сера образует два важнейших оксида: SO₂ (сернистый газ, степень окисления +4) и SO₃ (серный ангидрид, степень окисления +6).

Оксид серы(IV) SO₂:

  • Бесцветный газ с резким запахом, тяжелее воздуха.
  • Ядовит. Образуется при горении серы и сульфидов.
  • Вызывает кислотные дожди.

Химические свойства SO₂:

SO₂ + H₂O ⇄ H₂SO₃ (сернистая кислота)
SO₂ + 2NaOH → Na₂SO₃ + H₂O
2SO₂ + O₂ ⇄ 2SO₃ (кат., t°)

💡 SO₂ проявляет и окислительные, и восстановительные свойства.

Оксид серы(VI) SO₃:

  • Бесцветная жидкость (при обычных условиях), дымит на воздухе.
  • Сильный окислитель.
  • Хорошо растворяется в воде с образованием H₂SO₄.
SO₃ + H₂O → H₂SO₄
SO₃ + 2NaOH → Na₂SO₄ + H₂O

Сернистая кислота H₂SO₃: слабая, двухосновная, неустойчивая. Существует только в растворе.

SO₂ + H₂O ⇄ H₂SO₃ ⇄ 2H⁺ + SO₃²⁻

Соли сернистой кислоты — сульфиты и гидросульфиты:

  • Na₂SO₃ — сульфит натрия
  • K₂SO₃ — сульфит калия
  • NaHSO₃ — гидросульфит натрия

Соли серной кислоты — сульфаты:

  • Na₂SO₄ — сульфат натрия (глауберова соль)
  • K₂SO₄ — сульфат калия
  • BaSO₄ — сульфат бария (нерастворим — используется в рентгене)
  • CaSO₄·2H₂O — гипс
  • CuSO₄·5H₂O — медный купорос

Качественная реакция на сульфат-ион SO₄²⁻:

BaCl₂ + Na₂SO₄ → BaSO₄↓ (белый) + 2NaCl

💡 Осадок BaSO₄ нерастворим в воде и в кислотах.

Пример
Задание. Как отличить сульфит натрия от сульфата натрия?
Решение. Добавить к каждому раствору BaCl₂ и затем HCl.
— Na₂SO₃ + BaCl₂ → BaSO₃↓ (белый), который растворяется в HCl с выделением SO₂.
— Na₂SO₄ + BaCl₂ → BaSO₄↓ (белый), нерастворимый в HCl.

§8 Изучение свойств серной кислоты

Серная кислота H₂SO₄ — сильная двухосновная кислота, одна из важнейших в промышленности. Мировое производство H₂SO₄ — показатель развития химической промышленности страны.

Физические свойства:

  • Бесцветная маслянистая жидкость, тяжелее воды (ρ = 1,84 г/см³).
  • Нелетучая, гигроскопичная (поглощает воду из воздуха).
  • Смешивается с водой в любых соотношениях с сильным выделением теплоты.
  • Концентрированная H₂SO₄ обугливает органические вещества.

⚠ Правило разбавления: лить кислоту в воду, а не наоборот! Иначе вода закипит и разбрызгает кислоту.

Диссоциация:

H₂SO₄ → H⁺ + HSO₄⁻ (1-я ступень, сильная)
HSO₄⁻ ⇄ H⁺ + SO₄²⁻ (2-я ступень, слабая)

Химические свойства разбавленной H₂SO₄ (общие свойства кислот):

1. С металлами до H₂:

Zn + H₂SO₄ → ZnSO₄ + H₂↑

2. С основными оксидами:

CuO + H₂SO₄ → CuSO₄ + H₂O

3. С основаниями:

2NaOH + H₂SO₄ → Na₂SO₄ + 2H₂O

4. С солями:

BaCl₂ + H₂SO₄ → BaSO₄↓ + 2HCl

Особые свойства концентрированной H₂SO₄:

  • Сильный окислитель: реагирует с Cu, Ag, Hg (металлами правее H₂):
    Cu + 2H₂SO₄(конц.) → CuSO₄ + SO₂↑ + 2H₂O
  • Обугливает органику: сахар, бумага, дерево чернеют (выделяется C).
  • Осушитель: поглощает воду — используется для осушки газов.
  • При нагревании с неметаллами:
    C + 2H₂SO₄(конц.) → CO₂↑ + 2SO₂↑ + 2H₂O

Получение H₂SO₄ в промышленности — контактный способ:

  1. Обжиг пирита: 4FeS₂ + 11O₂ → 2Fe₂O₃ + 8SO₂
  2. Окисление SO₂ до SO₃: 2SO₂ + O₂ ⇄ 2SO₃ (кат. V₂O₅)
  3. Растворение SO₃ в H₂SO₄ (получение олеума).

Качественная реакция на SO₄²⁻: с BaCl₂ — белый осадок BaSO₄, нерастворимый в кислотах.

Применение H₂SO₄: производство удобрений, аккумуляторы, очистка нефтепродуктов, получение других кислот, осушка газов.

⚠ Техника безопасности: серная кислота — едкое вещество. Работать в защитных очках и перчатках, при попадании на кожу — обильно промыть водой и обработать раствором соды.

§10 Аммиак. Соли аммония

Аммиак NH₃ — бесцветный газ с резким характерным запахом, почти в 2 раза легче воздуха. Очень хорошо растворим в воде (в 1 объёме воды — до 700 объёмов NH₃).

Строение молекулы NH₃: пирамидальная (форма тригональной пирамиды). Азот имеет неподелённую электронную пару, поэтому может образовывать донорно-акцепторную связь.

Химические свойства аммиака:

1. Взаимодействие с водой — образуется слабое основание NH₄OH:

NH₃ + H₂O ⇄ NH₄OH ⇄ NH₄⁺ + OH⁻

Раствор аммиака (нашатырный спирт) имеет щелочную реакцию — фенолфталеин становится малиновым.

2. Взаимодействие с кислотами — образует соли аммония:

NH₃ + HCl → NH₄Cl
2NH₃ + H₂SO₄ → (NH₄)₂SO₄

3. Горение в кислороде:

4NH₃ + 3O₂ → 2N₂ + 6H₂O (без катализатора)
4NH₃ + 5O₂ → 4NO + 6H₂O (с катализатором, Pt)

4. Восстановительные свойства:

2NH₃ + 3CuO → 3Cu + N₂ + 3H₂O
Соли аммония Соли, содержащие катион аммония NH₄⁺. Образуются при взаимодействии аммиака с кислотами.
Примеры: NH₄Cl (нашатырь), (NH₄)₂SO₄, NH₄NO₃ (аммиачная селитра).

Химические свойства солей аммония:

1. Диссоциация:

NH₄Cl → NH₄⁺ + Cl⁻

2. Взаимодействие со щелочами — выделяется аммиак (качественная реакция на NH₄⁺):

NH₄Cl + NaOH → NaCl + NH₃↑ + H₂O

💡 Запах аммиака и посинение влажной лакмусовой бумажки — признак выделения NH₃.

3. Разложение при нагревании:

NH₄Cl → NH₃↑ + HCl↑ (при t°)
NH₄NO₃ → N₂O↑ + 2H₂O (при t°)

4. Взаимодействие с кислотами (если образуется осадок или газ):

(NH₄)₂CO₃ + 2HCl → 2NH₄Cl + H₂O + CO₂↑

Применение солей аммония:

  • NH₄NO₃ — азотное удобрение (аммиачная селитра).
  • (NH₄)₂SO₄ — удобрение.
  • NH₄Cl — электролит в сухих батарейках, паяльная кислота.
  • NH₄HCO₃ — разрыхлитель теста, пищевая добавка.
Пример
Задание. Как отличить соль аммония от других солей?
Решение. Добавить к раствору соли щёлочь (NaOH) и нагреть. Если выделяется газ с резким запахом (NH₃), который синеет влажную лакмусовую бумажку, — это соль аммония.
NH₄Cl + NaOH → NaCl + NH₃↑ + H₂O

§11 Получение аммиака и изучение его свойств

Лабораторный способ получения аммиака: действие щёлочи на соль аммония при нагревании.

2NH₄Cl + Ca(OH)₂ → CaCl₂ + 2NH₃↑ + 2H₂O

Или проще — со щёлочью:

NH₄Cl + NaOH → NaCl + NH₃↑ + H₂O (при t°)

Собирают аммиак в перевёрнутую вверх дном пробирку, потому что NH₃ легче воздуха.

Промышленный способ (синтез Габера):

N₂ + 3H₂ ⇄ 2NH₃ + Q (кат. Fe, t° = 400–500 °C, p = 200–1000 атм)

Условия подобраны так, чтобы сместить равновесие в сторону аммиака: высокое давление, умеренная температура, катализатор.

Лабораторная работа «Получение аммиака и изучение его свойств»:

  1. В пробирку насыпать NH₄Cl и Ca(OH)₂, перемешать.
  2. Закрыть пробкой с газоотводной трубкой.
  3. Нагреть на спиртовке.
  4. Собрать NH₃ в перевёрнутую пробирку (вверх дном).
  5. Опустить пробирку с NH₃ в воду с фенолфталеином — вода втянется, окрасится в малиновый цвет (щёлочная среда).
  6. Поднести к отверстию пробирки стеклянную палочку, смоченную HCl — появятся белые клубы дыма (NH₄Cl).

Признаки:

  • Резкий запах аммиака.
  • Фенолфталеин малиновый — среда щелочная.
  • Белый дым с HCl — образование NH₄Cl.

⚠ Техника безопасности: аммиак токсичен, работать в вытяжном шкафу; при попадании раствора на кожу — промыть водой.

Пример
Задание. Как собрать аммиак в лаборатории?
Решение. NH₃ легче воздуха (M = 17 < 29), поэтому собирают в перевёрнутую вверх дном пробирку. Определить заполнение можно по посинению влажной лакмусовой бумажки, поднесённой к отверстию.

Азотистая кислота HNO₂ — слабая, неустойчивая. Соли — нитриты (NaNO₂, KNO₂).

N₂O₃ + H₂O → 2HNO₂

Азотная кислота HNO₃ — сильная одноосновная кислота, сильный окислитель.

N₂O₅ + H₂O → 2HNO₃

  • Сильный окислитель: реагирует почти со всеми металлами (кроме Au, Pt), при этом выделяется не водород, а оксиды азота.

  • Пассивирует Al, Fe, Cr (на холоде концентрированная HNO₃ создаёт защитную плёнку).
  • С неметаллами:
    C + 4HNO₃(конц.) → CO₂↑ + 4NO₂↑ + 2H₂O

Соли азотной кислоты — нитраты (селитры):

  • NaNO₃ — натриевая селитра;
  • KNO₃ — калиевая селитра (удобрение, компонент пороха);
  • NH₄NO₃ — аммиачная селитра (удобрение);
  • Ca(NO₃)₂ — кальциевая селитра.

Разложение нитратов при нагревании:

2KNO₃ → 2KNO₂ + O₂↑ (для металлов средней активности)
2Cu(NO₃)₂ → 2CuO + 4NO₂↑ + O₂↑

Качественная реакция на нитрат-ион NO₃⁻: с концентрированной H₂SO₄ и медью — выделяется бурый газ NO₂.

§15 Кислородные соединения углерода

Углерод образует два важнейших оксида: CO (угарный газ, +2) и CO₂ (углекислый газ, +4).

Оксид углерода(II) CO — угарный газ:

  • Бесцветный газ без запаха, легче воздуха.
  • Очень ядовит — связывает гемоглобин крови, вызывая кислородное голодание.
  • Несолеобразующий оксид.
  • Хороший восстановитель (используется в металлургии).

Химические свойства CO:

2CO + O₂ → 2CO₂ (горение)
Fe₂O₃ + 3CO → 2Fe + 3CO₂ (восстановление)
CO + CuO → Cu + CO₂

Оксид углерода(IV) CO₂ — углекислый газ:

  • Бесцветный газ без запаха, тяжелее воздуха.
  • Не поддерживает горение и дыхание.
  • Кислотный оксид — реагирует с водой, щелочами, основными оксидами.
  • Составляет 0,03–0,04 % атмосферы; выделяется при дыхании.
  • Твёрдый CO₂ — «сухой лёд» (возгоняется при −78 °C).

Химические свойства CO₂:

CO₂ + H₂O ⇄ H₂CO₃ (угольная кислота)
CO₂ + Ca(OH)₂ → CaCO₃↓ + H₂O (помутнение известковой воды)
CO₂ + 2NaOH → Na₂CO₃ + H₂O
CO₂ + CaO → CaCO₃

💡 Помутнение известковой воды — качественная реакция на углекислый газ. При пропускании избытка CO₂ осадок растворяется:
CaCO₃ + CO₂ + H₂O → Ca(HCO₃)₂

Угольная кислота H₂CO₃ — слабая, неустойчивая, существует только в растворе:

CO₂ + H₂O ⇄ H₂CO₃ ⇄ 2H⁺ + CO₃²⁻

Соли угольной кислоты:

  • Карбонаты — средние соли: Na₂CO₃, K₂CO₃, CaCO₃, MgCO₃.
  • Гидрокарбонаты — кислые соли: NaHCO₃, KHCO₃, Ca(HCO₃)₂.

Применение:

  • CO — восстановитель в металлургии.
  • CO₂ — газированные напитки, огнетушители, «сухой лёд», пищевая добавка E290.
  • Na₂CO₃ — производство стекла, мыла, моющих средств.
  • NaHCO₃ — пищевая сода, медицина.
  • CaCO₃ — строительство, мел, мрамор.
Пример

Решение.
2CO + O₂ → 2CO₂

CO₂ + 2NaOH → Na₂CO₃ + H₂O
CaCO₃ → CaO + CO₂↑

§16 Получение углекислого газа. Качественная реакция на карбонат-ионы

Лабораторный способ получения CO₂: действие кислоты на карбонат или гидрокарбонат:

CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑
Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑
NaHCO₃ + HCl → NaCl + H₂O + CO₂↑

Промышленный способ: обжиг известняка:

CaCO₃ → CaO + CO₂↑ (при t° ≈ 1000 °C)

Собирают CO₂ в пробирку, поставленную вверх дном, потому что CO₂ тяжелее воздуха.

Качественная реакция на карбонат-ион CO₃²⁻ Действие сильной кислоты — выделяется газ CO₂ (вскипание), который мутнеет известковую воду:
1) Обнаружение газа: Ca(OH)₂ + CO₂ → CaCO₃↓ + H₂O
2) Реакция с кислотой: Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑

Лабораторная работа «Получение CO₂ и изучение его свойств»:

  1. В пробирку поместить немного мела (CaCO₃) или Na₂CO₃.
  2. Прилить HCl — наблюдать вскипание.
  3. Закрыть пробкой с газоотводной трубкой.
  4. Собрать газ в пробирку, перевёрнутую вверх дном.
  5. Пропустить газ через известковую воду — помутнение (CaCO₃).
  6. Продолжать пропускать газ — помутнение исчезает (образование Ca(HCO₃)₂).

Признаки:

  • Вскипание при действии кислоты (выделение газа).
  • Помутнение известковой воды — белый осадок CaCO₃.
  • Горящая лучинка гаснет в CO₂ (газ не поддерживает горение).

Устранение временной жёсткости воды (связано с гидрокарбонатами):

Ca(HCO₃)₂ → CaCO₃↓ + H₂O + CO₂↑ (при кипячении)
Пример
Задание. Как доказать, что в пробирке находится карбонат натрия?
Решение. Прилить к раствору HCl — если наблюдается вскипание (выделение газа), пропустить газ через известковую воду — помутнение. Это доказывает наличие CO₃²⁻.

§17 Углеводороды

Углеводороды — органические соединения, состоящие только из углерода и водорода. Это важнейший класс органических веществ.

Углеводороды Органические соединения, молекулы которых состоят из атомов углерода и водорода. Делятся на предельные (алканы), непредельные (алкены, алкины) и ароматические (арены).

1. Предельные углеводороды (алканы) — общая формула CₙH₂ₙ₊₂:

НазваниеФормулаАгрегатное состояние
МетанCH₄газ
ЭтанC₂H₆газ
ПропанC₃H₈газ
БутанC₄H₁₀газ
ПентанC₅H₁₂жидкость
ГексанC₆H₁₄жидкость

Химические свойства метана:

CH₄ + 2O₂ → CO₂ + 2H₂O (горение)
CH₄ + Cl₂ → CH₃Cl + HCl (замещение, на свету)
CH₄ → C + 2H₂ (разложение при t° = 1000 °C)

2. Непредельные углеводороды (алкены) — общая формула CₙH₂ₙ. Содержат двойную связь C=C.

  • Этилен C₂H₄ — газ, ускоряет созревание плодов.
  • Пропилен C₃H₆ — газ, сырьё для полимеров.

Свойства этилена:

C₂H₄ + 3O₂ → 2CO₂ + 2H₂O (горение)
C₂H₄ + Br₂ → C₂H₄Br₂ (присоединение — обесцвечивание бромной воды)
C₂H₄ + H₂ → C₂H₆ (гидрирование, кат.)
nC₂H₄ → (−CH₂−CH₂−)ₙ (полиэтилен)

3. Алкины — общая формула CₙH₂ₙ₋₂. Содержат тройную связь C≡C.

  • Ацетилен C₂H₂ — газ, применяется для сварки.

Свойства ацетилена:

2C₂H₂ + 5O₂ → 4CO₂ + 2H₂O (горение, t° = 3000 °C)
C₂H₂ + 2Br₂ → C₂H₂Br₄

4. Арены — ароматические углеводороды, содержат бензольное кольцо.

  • Бензол C₆H₆ — жидкость с характерным запахом, токсичен.

Свойства бензола:

2C₆H₆ + 15O₂ → 12CO₂ + 6H₂O (горение, коптящее пламя)
C₆H₆ + Br₂ → C₆H₅Br + HBr (замещение, кат. FeBr₃)

Применение углеводородов:

  • Метан, пропан, бутан — топливо (природный газ, сжиженный газ).
  • Этилен — производство полиэтилена, этиленгликоля.
  • Ацетилен — сварка и резка металлов.
  • Бензол — производство красителей, лекарств, пластмасс.
Пример

Решение.

C₂H₄ + H₂O → C₂H₅OH (кат., t°)
nC₂H₄ → (−CH₂−CH₂−)ₙ

§18 Кислородсодержащие органические соединения

Кислородсодержащие органические соединения — вещества, содержащие кроме C и H ещё и O. Важнейшие классы: спирты, карбоновые кислоты, альдегиды, сложные эфиры, углеводы.

1. Спирты — органические соединения, содержащие гидроксильную группу −OH.

  • Метанол CH₃OH — ядовитая жидкость (слепота, смерть).
  • Этанол C₂H₅OH — винный спирт, применяется в медицине, как растворитель.
  • Глицерин C₃H₈O₃ — трёхатомный спирт, вязкая жидкость.

Свойства этанола:

C₂H₅OH + 3O₂ → 2CO₂ + 3H₂O (горение)
2C₂H₅OH + 2Na → 2C₂H₅ONa + H₂↑ (с натрием)
C₂H₅OH → C₂H₄ + H₂O (дегидратация, кат.)

2. Карбоновые кислоты — органические кислоты, содержащие карбоксильную группу −COOH.

  • Муравьиная HCOOH — самая сильная из органических.
  • Уксусная CH₃COOH — слабая, в уксусе (6–9 %).
  • Лимонная C₆H₈O₇ — в цитрусах.

Свойства уксусной кислоты:

CH₃COOH ⇄ CH₃COO⁻ + H⁺ (слабая кислота)
CH₃COOH + NaOH → CH₃COONa + H₂O
2CH₃COOH + Mg → (CH₃COO)₂Mg + H₂↑

3. Альдегиды — содержат группу −CHO.

  • Формальдегид CH₂O — газ, раствор (формалин) — антисептик.
  • Ацетальдегид CH₃CHO — жидкость.

Качественная реакция на альдегиды — «серебряное зеркало» с Ag₂O:

CH₃CHO + Ag₂O → CH₃COOH + 2Ag↓

4. Углеводы — природные соединения состава Cₙ(H₂O)ₘ:

  • Глюкоза C₆H₁₂O₆ — моносахарид, «виноградный сахар».
  • Сахароза C₁₂H₂₂O₁₁ — дисахарид, обычный сахар.
  • Крахмал (C₆H₁₀O₅)ₙ — полисахарид, в картофеле, хлебе.
  • Целлюлоза (C₆H₁₀O₅)ₙ — полисахарид, в древесине, хлопке.

Качественные реакции на крахмал: с иодом — синее окрашивание.

Применение:

  • Этанол — медицина, топливо, растворитель.
  • Уксусная кислота — консервирование, химическая промышленность.
  • Глюкоза — в медицине (питательные растворы), в пищевой промышленности.
  • Сахароза — пищевой сахар.
Пример

Решение.

CH₃COOH + NaOH → CH₃COONa + H₂O

§19 Кремний и его соединения. Силикатная промышленность

Кремний Si — второй по распространённости элемент в земной коре после кислорода (~27 %). В свободном виде не встречается, только в соединениях — SiO₂ (кремнезём) и силикатах.

Строение: атомная кристаллическая решётка (как у алмаза), тёмно-серое твёрдое вещество с металлическим блеском.

Химические свойства кремния:

1. С кислородом:

Si + O₂ → SiO₂

2. С галогенами:

Si + 2Cl₂ → SiCl₄

3. Со щелочами:

Si + 2NaOH + H₂O → Na₂SiO₃ + 2H₂↑

4. С металлами:

2Mg + Si → Mg₂Si (силицид магния)

Оксид кремния(IV) SiO₂ — кварц, песок, кремнезём:

  • Твёрдое, тугоплавкое (t° пл. ≈ 1700 °C) вещество с атомной решёткой.
  • Кислотный оксид — реагирует со щелочами и оксидами металлов:
SiO₂ + 2NaOH → Na₂SiO₃ + H₂O
SiO₂ + CaO → CaSiO₃

💡 SiO₂ не реагирует с водой, потому что H₂SiO₃ — нерастворимая кислота.

Кремниевая кислота H₂SiO₃ — слабая, нерастворимая, образует студенистый осадок:

Na₂SiO₃ + 2HCl → H₂SiO₃↓ + 2NaCl

Силикаты — соли кремниевой кислоты: Na₂SiO₃, K₂SiO₃, CaSiO₃. Растворимые силикаты (Na₂SiO₃, K₂SiO₃) — «жидкое стекло».

Силикатная промышленность Отрасль, производящая стекло, керамику, цемент на основе соединений кремния.

1. Производство стекла:

SiO₂ + Na₂CO₃ → Na₂SiO₃ + CO₂↑
SiO₂ + CaCO₃ → CaSiO₃ + CO₂↑

Стекло — смесь Na₂SiO₃, CaSiO₃, SiO₂. Виды: оконное, кварцевое, хрустальное, оптическое, цветное.

2. Производство керамики: глины, фарфор, фаянс. Основа — минерал каолинит Al₂O₃·2SiO₂·2H₂O.

3. Производство цемента: обжиг смеси глины и известняка:

CaCO₃ + SiO₂ → CaSiO₃ + CO₂↑

Цемент + вода + песок + щебень = бетон.

Применение кремния: полупроводники (микросхемы, солнечные батареи), сплавы, стекло.

Пример
Задание. Напишите уравнения: Si + O₂, SiO₂ + NaOH, Na₂SiO₃ + HCl.
Решение.
Si + O₂ → SiO₂
SiO₂ + 2NaOH → Na₂SiO₃ + H₂O
Na₂SiO₃ + 2HCl → H₂SiO₃↓ + 2NaCl

§20 Получение неметаллов

Неметаллы получают разными способами: из природных соединений, электролизом, окислением или восстановлением.

1. Кислород — из воздуха (фракционная перегонка) или электролизом воды:

2H₂O → 2H₂↑ + O₂↑ (электролиз)

2. Азот — из воздуха (фракционная перегонка).

3. Водород:

CH₄ + H₂O → CO + 3H₂ (кат., t°) — конверсия метана
2H₂O → 2H₂↑ + O₂↑ (электролиз)
Zn + 2HCl → ZnCl₂ + H₂↑ (лаборатория)

4. Хлор — электролизом раствора NaCl:

2NaCl + 2H₂O → 2NaOH + Cl₂↑ + H₂↑ (электролиз)

5. Сера — из природных месторождений или из H₂S:

2H₂S + O₂ → 2S + 2H₂O (неполное окисление)

6. Фосфор — восстановлением фосфатов коксом при высокой температуре:

Ca₃(PO₄)₂ + 5C + 3SiO₂ → 3CaSiO₃ + 2P + 5CO↑

7. Кремний — восстановлением коксом:

SiO₂ + 2C → Si + 2CO↑ (в электропечи)

8. Азотсодержащие удобрения получают из аммиака (синтез Габера).

Применение неметаллов:

  • Кислород — дыхание, металлургия, медицина.
  • Водород — топливо, синтез аммиака, восстановитель.
  • Хлор — обеззараживание воды, получение HCl, пластмасс.
  • Азот — инертная среда, производство удобрений.
  • Сера — производство H₂SO₄, вулканизация резины.
  • Фосфор — удобрения, спички, моющие средства.
  • Кремний — электроника, сплавы, стекло.
Пример
Задание. Как в лаборатории получить водород?
Решение. Действием кислоты на активный металл:
Zn + 2HCl → ZnCl₂ + H₂↑
Собирают в перевёрнутую пробирку (H₂ легче воздуха).

§21 Получение важнейших химических соединений неметаллов

Важнейшие соединения неметаллов — кислоты, аммиак, оксиды — получают в промышленности в огромных количествах.

1. Получение соляной кислоты HCl:

H₂ + Cl₂ → 2HCl (синтез из простых веществ)

Образуется HCl-газ, который растворяют в воде.

2. Получение серной кислоты H₂SO₄ — контактный способ:

  1. Обжиг пирита: 4FeS₂ + 11O₂ → 2Fe₂O₃ + 8SO₂
  2. Окисление SO₂: 2SO₂ + O₂ ⇄ 2SO₃ (кат. V₂O₅, t° = 450 °C)
  3. Поглощение SO₃: SO₃ + H₂O → H₂SO₄

3. Получение азотной кислоты HNO₃ — аммиачный способ:

  1. Синтез аммиака: N₂ + 3H₂ ⇄ 2NH₃ (Fe, 500 °C, 300 атм)
  2. Окисление аммиака: 4NH₃ + 5O₂ → 4NO + 6H₂O (кат. Pt)
  3. Окисление NO: 2NO + O₂ → 2NO₂
  4. Поглощение NO₂: 4NO₂ + O₂ + 2H₂O → 4HNO₃

4. Получение аммиака NH₃ (синтез Габера):

N₂ + 3H₂ ⇄ 2NH₃ + Q (Fe, 400–500 °C, 200–1000 атм)

5. Получение фосфорной кислоты H₃PO₄:

P₂O₅ + 3H₂O → 2H₃PO₄

В промышленности — обработкой фосфатов серной кислотой:

Ca₃(PO₄)₂ + 3H₂SO₄ → 3CaSO₄ + 2H₃PO₄

6. Получение аммиачных удобрений:

  • Аммиачная селитра: NH₃ + HNO₃ → NH₄NO₃
  • Сульфат аммония: 2NH₃ + H₂SO₄ → (NH₄)₂SO₄
  • Карбамид (мочевина): 2NH₃ + CO₂ → CO(NH₂)₂ + H₂O

Значение производства:

  • Серная кислота — «хлеб химической промышленности», по её производству судят о развитии страны.
  • Азотные удобрения — повышают урожайность.
  • Азотная кислота — производство удобрений и взрывчатки.
  • Аммиак — сырьё для удобрений и азотной кислоты.
Пример
Задание. Напишите уравнения всех стадий получения азотной кислоты из азота воздуха.
Решение.
1) N₂ + 3H₂ ⇄ 2NH₃ (Fe, 500 °C, 300 атм)
2) 4NH₃ + 5O₂ → 4NO + 6H₂O (кат. Pt)
3) 2NO + O₂ → 2NO₂
4) 4NO₂ + O₂ + 2H₂O → 4HNO₃

§1 Общая характеристика металлов

Металлы — химические элементы, атомы которых отдают электроны, превращаясь в положительно заряженные ионы. К металлам относится большинство известных элементов (~90).

Металлы Химические элементы, атомы которых имеют на внешнем уровне 1–3 электрона и легко их отдают, образуя положительные ионы. В отличие от неметаллов, у металлов большие радиусы атомов и низкая электроотрицательность.

Положение в ПСХЭ:

  • Все элементы побочных подгрупп — металлы (Cu, Fe, Zn, Cr…).
  • Металлы — в левой нижней части главных подгрупп (IA, IIA, IIIA — кроме B).
  • Исключения: H, B, C, Si, N, P, O, S, галогены, благородные газы — неметаллы.

Строение атомов металлов:

  • На внешнем уровне 1–3 электрона (исключение — некоторые переходные металлы).
  • Радиусы атомов большие.
  • Низкая электроотрицательность (0,7–2,0).
  • Легко отдают электроны, превращаясь в катионы.
Металлическая связь Химическая связь в металлах, при которой положительно заряженные ионы металла удерживаются в узлах решётки за счёт обобществлённых электронов. Эти электроны свободно перемещаются по всему кристаллу — «электронный газ».

Физические свойства металлов:

  • Металлический блеск — благодаря отражению света свободными электронами.
  • Электро- и теплопроводность — из-за свободно движущихся электронов.
  • Ковкость и пластичность — слои ионов легко смещаются без разрушения решётки.
  • Твёрдость: от очень мягких (Na, K — режутся ножом) до очень твёрдых (Cr, W).
  • Плотность: лёгкие (Li, Na, K) и тяжёлые (Pb, Os, Ir).
  • Температуры плавления: легкоплавкие (Hg — жидкость, Cs — 28 °C) и тугоплавкие (W — 3410 °C).
  • Цвет: большинство — серебристо-белые (Fe, Al), некоторые — цветные (Cu — красная, Au — жёлтое, Ag — белое).

Классификация металлов:

§2 Химические свойства металлов

Все металлы проявляют восстановительные свойства — отдают электроны. Но их активность разная, поэтому и реакции идут по-разному.

1. С неметаллами — образуют бинарные соединения:

2Na + Cl₂ → 2NaCl (хлорид натрия)
4Al + 3O₂ → 2Al₂O₃ (оксид алюминия)
Fe + S → FeS (сульфид железа)
3Ca + N₂ → Ca₃N₂ (нитрид кальция)

2. С водой (зависит от активности):

  • Активные (Na, K, Li) — бурно, с образованием щёлочи и H₂:
    2Na + 2H₂O → 2NaOH + H₂↑
  • Средней активности (Mg, Fe) — при нагревании:
    Mg + 2H₂O → Mg(OH)₂ + H₂↑
    3Fe + 4H₂O → Fe₃O₄ + 4H₂↑
  • Малоактивные (Cu, Ag, Au) — не реагируют.

3. С кислотами:

  • Металлы до H₂ реагируют с разбавленными кислотами (HCl, H₂SO₄):
    Zn + 2HCl → ZnCl₂ + H₂↑
  • Металлы после H₂ с обычными кислотами не реагируют, но реагируют с HNO₃ (и конц. H₂SO₄):
    Cu + 4HNO₃(конц.) → Cu(NO₃)₂ + 2NO₂↑ + 2H₂O

4. С солями (более активный вытесняет менее активный):

Fe + CuSO₄ → FeSO₄ + Cu↓
Cu + 2AgNO₃ → Cu(NO₃)₂ + 2Ag↓

⚠ Металлы I и II главных подгрупп (Na, K, Ca) сначала реагируют с водой, поэтому с растворами солей так не взаимодействуют.

5. С оксидами металлов — восстановление менее активного металла:

2Al + Fe₂O₃ → Al₂O₃ + 2Fe (алюминотермия)
3Mg + Cr₂O₃ → 3MgO + 2Cr
Пример

Решение.

Fe + 2HCl → FeCl₂ + H₂↑
Cu + 2AgNO₃ → Cu(NO₃)₂ + 2Ag↓

§3 Общая характеристика элементов IA группы — щелочные металлы

Щелочные металлы — элементы IA группы: литий Li, натрий Na, калий K, рубидий Rb, цезий Cs и радиоактивный франций Fr.

Щелочные металлы Элементы IA группы, на внешнем уровне которых 1 электрон (ns¹). Легко его отдают, образуя сильные основания — щёлочи.

Строение: на внешнем уровне 1 электрон. Металлические свойства усиливаются сверху вниз.

Физические свойства:

  • Серебристо-белые мягкие металлы (Na, K режутся ножом).
  • Лёгкие (Li — самый лёгкий металл).
  • Низкие температуры плавления (K — 63, Cs — 28 °C).
  • Хранятся под слоем керосина (окисляются на воздухе).

Химические свойства (очень активны):

1. С кислородом:

4Li + O₂ → 2Li₂O (оксид)
2Na + O₂ → Na₂O₂ (пероксид)
K + O₂ → KO₂ (супероксид)

2. С водой (реакция бурная):

2Na + 2H₂O → 2NaOH + H₂↑
2K + 2H₂O → 2KOH + H₂↑ (со вспышкой)

3. С галогенами:

2Na + Cl₂ → 2NaCl

4. С водородом:

2Na + H₂ → 2NaH (гидрид натрия)

Важнейшие соединения:

  • NaOH — гидроксид натрия (щёлочь, едкий натр).
  • Na₂CO₃ — карбонат натрия (сода).
  • NaHCO₃ — гидрокарбонат натрия (пищевая сода).
  • NaCl — поваренная соль.
  • KOH — гидроксид калия (едкое кали).
  • K₂CO₃ — поташ.
  • KNO₃ — калиевая селитра (удобрение).

Качественная реакция на Na⁺: жёлтое окрашивание пламени.
На K⁺: фиолетовое окрашивание пламени.

Применение:

  • Na, K — восстановители, теплоносители в ядерных реакторах.
  • NaCl — пища, консервирование, получение хлора и соды.
  • NaOH — производство мыла, бумаги, моющих средств.
  • NaHCO₃ — пищевая сода, медицина.
Пример

Решение.

2Na + 2H₂O → 2NaOH + H₂↑
2Na + Cl₂ → 2NaCl
2Na + H₂ → 2NaH

§4 Общая характеристика элементов IIA группы — щёлочноземельные металлы

Щёлочноземельные металлы — элементы IIA группы: бериллий Be, магний Mg, кальций Ca, стронций Sr, барий Ba, радий Ra. Be и Mg — не щёлочноземельные (их оксиды не дают щёлочи), остальные — да.

Щёлочноземельные металлы Ca, Sr, Ba, Ra — элементы IIA группы, образующие щёлочи при взаимодействии оксидов с водой. На внешнем уровне 2 электрона (ns²).

Строение: 2 электрона на внешнем уровне, легко их отдают. Металлические свойства усиливаются сверху вниз.

Физические свойства: серебристо-белые, твёрже щелочных, t° пл. выше (Be — 1287 °C).

Химические свойства (активные):

1. С кислородом — образуют оксиды:

2Ca + O₂ → 2CaO

2. С водой (Ca, Sr, Ba — при обычных условиях):

Ca + 2H₂O → Ca(OH)₂ + H₂↑
Mg + 2H₂O → Mg(OH)₂ + H₂↑ (при нагревании)

3. С кислотами:

Mg + 2HCl → MgCl₂ + H₂↑

4. С неметаллами:

Ca + Cl₂ → CaCl₂
3Ca + N₂ → Ca₃N₂

Важнейшие соединения кальция:

  • CaO — оксид кальция (негашёная известь).
  • Ca(OH)₂ — гидроксид кальция (гашёная известь, известковая вода).
  • CaCO₃ — карбонат кальция (мел, мрамор, известняк).
  • CaSO₄·2H₂O — гипс.
  • Ca₃(PO₄)₂ — фосфат кальция (в костях, зубах).

Важнейшие соединения магния:

  • MgO — оксид магния (жжёная магнезия).
  • Mg(OH)₂ — гидроксид магния.
  • MgSO₄·7H₂O — английская соль.

Качественные реакции:

  • Ca²⁺ — кирпично-красное окрашивание пламени, с CO₃²⁻ → белый осадок CaCO₃.
  • Ba²⁺ — жёлто-зелёное окрашивание пламени, с SO₄²⁻ → белый осадок BaSO₄.

Применение:

  • CaO, Ca(OH)₂ — строительство (известь, побелка).
  • CaCO₃ — строительство, мел, мрамор.
  • CaSO₄·2H₂O — гипс в медицине и строительстве.
  • Mg — лёгкие сплавы, фото-вспышки.

Решение.

CaO + H₂O → Ca(OH)₂
Ca(OH)₂ + CO₂ → CaCO₃↓ + H₂O

§5 Жёсткость воды и способы её устранения
Жёсткость воды Свойство воды, связанное с содержанием в ней растворимых солей кальция и магния (Ca²⁺, Mg²⁺).

Виды жёсткости:

  • Временная (карбонатная) — обусловлена гидрокарбонатами Ca(HCO₃)₂ и Mg(HCO₃)₂. Устраняется кипячением:
    Ca(HCO₃)₂ → CaCO₃↓ + H₂O + CO₂↑
  • Постоянная (некарбонатная) — обусловлена сульфатами и хлоридами кальция и магния (CaSO₄, MgSO₄, CaCl₂). Кипячением не устраняется.
  • Общая — сумма временной и постоянной.

Проблемы, вызываемые жёсткой водой:

  • Образование накипи на стенках котлов и чайников.
  • Плохое пенообразование мыла (расход мыла увеличивается).
  • Ухудшение вкуса и качества продуктов.
  • В промышленности — выход из строя оборудования.

Способы устранения жёсткости:

1. Кипячение — устраняет только временную жёсткость:

Ca(HCO₃)₂ → CaCO₃↓ + H₂O + CO₂↑

2. Добавление соды Na₂CO₃ — осаждает ионы Ca²⁺ и Mg²⁺:

CaCl₂ + Na₂CO₃ → CaCO₃↓ + 2NaCl
MgSO₄ + Na₂CO₃ → MgCO₃↓ + Na₂SO₄

3. Добавление гашёной извести Ca(OH)₂ — устраняет временную жёсткость:

Ca(HCO₃)₂ + Ca(OH)₂ → 2CaCO₃↓ + 2H₂O

4. Ионообменный способ — пропускание воды через ионообменные смолы, которые обменивают Ca²⁺ и Mg²⁺ на Na⁺.

5. Дистилляция — перегонка воды (в лаборатории).

Значение: умягчённая вода нужна в промышленности (котлы, теплообменники), в быту (стирка, мытьё), в медицине.

Пример
Задание. Как устранить временную жёсткость воды?
Решение. Кипячением или добавлением Ca(OH)₂:
Ca(HCO₃)₂ → CaCO₃↓ + H₂O + CO₂↑ (при кипячении).
Ca(HCO₃)₂ + Ca(OH)₂ → 2CaCO₃↓ + 2H₂O (с известью).

§6 Алюминий и его соединения

Алюминий Al — элемент IIIA группы, самый распространённый металл в земной коре (8,8 %). По распространённости — 3-й элемент после O и Si.

Строение атома: на внешнем уровне 3 электрона (3s²3p¹). Легко отдаёт их, образуя Al³⁺.

Физические свойства:

  • Серебристо-белый лёгкий металл (ρ = 2,7 г/см³).
  • Пластичный, ковкий, хорошо проводит ток и тепло.
  • t° пл. = 660 °C.
  • На воздухе покрывается прочной оксидной плёнкой Al₂O₃, защищающей от коррозии.

Химические свойства:

1. С кислородом (при нагревании):

4Al + 3O₂ → 2Al₂O₃

2. С галогенами:

2Al + 3Cl₂ → 2AlCl₃

3. С кислотами:

2Al + 6HCl → 2AlCl₃ + 3H₂↑
2Al + 6HNO₃(разб.) → 2Al(NO₃)₃ + 3H₂↑ (но с конц. HNO₃ — пассивация)

4. Со щелочами (амфотерность):

2Al + 2NaOH + 2H₂O → 2NaAlO₂ + 3H₂↑

5. С оксидами металлов (алюминотермия):

2Al + Fe₂O₃ → Al₂O₃ + 2Fe

Амфотерность соединений алюминия:

  • Al₂O₃ — амфотерный оксид:
    Al₂O₃ + 6HCl → 2AlCl₃ + 3H₂O
    Al₂O₃ + 2NaOH → 2NaAlO₂ + H₂O
  • Al(OH)₃ — амфотерный гидроксид:
    Al(OH)₃ + 3HCl → AlCl₃ + 3H₂O
    Al(OH)₃ + NaOH → Na[Al(OH)₄]

Качественная реакция на Al³⁺: с NaOH образуется белый студенистый осадок Al(OH)₃, который растворяется в избытке щёлочи.

Применение:

  • Самолётостроение, автомобилестроение (лёгкие сплавы — дюралюминий).
  • Электротехника (провода, кабели).
  • Посуда, фольга.
  • Восстановитель в металлургии (алюминотермия).

§7 Железо и его соединения

Железо Fe — элемент VIIIB группы, один из самых важных металлов. В земной коре ~4,65 %. Второй по распространённости металл после алюминия.

Строение атома: на внешнем уровне 2 электрона, но есть и d-подуровень. Проявляет степени окисления +2 и +3 (реже +6).

Физические свойства:

  • Серебристо-белый металл с характерным блеском.
  • Плотный (ρ = 7,87 г/см³), тугоплавкий (t° пл. = 1539 °C).
  • Обладает ферромагнитными свойствами (притягивается магнитом).

Химические свойства:

1. С кислородом — образует оксиды:

3Fe + 2O₂ → Fe₃O₄ (железная окалина)
4Fe + 3O₂ → 2Fe₂O₃ (ржавчина, при влажности)

2. С галогенами:

2Fe + 3Cl₂ → 2FeCl₃

3. С кислотами:

Fe + 2HCl → FeCl₂ + H₂↑ (разб. кислота → Fe²⁺)
2Fe + 6H₂SO₄(конц.) → Fe₂(SO₄)₃ + 3SO₂↑ + 6H₂O (горячая)

⚠ С концентрированными HNO₃ и H₂SO₄ (на холоде) железо пассивируется.

4. С солями:

Fe + CuSO₄ → FeSO₄ + Cu↓

5. С водой (при нагревании):

3Fe + 4H₂O → Fe₃O₄ + 4H₂↑

Соединения железа(II):

  • FeO — оксид железа(II), чёрный порошок.
  • Fe(OH)₂ — гидроксид железа(II), зеленоватый осадок, быстро окисляется на воздухе.
  • FeSO₄·7H₂O — железный купорос.
  • FeCl₂ — хлорид железа(II).

Соединения железа(III):

  • Fe₂O₃ — оксид железа(III), красный железняк.
  • Fe(OH)₃ — гидроксид железа(III), бурый осадок.
  • FeCl₃ — хлорид железа(III).
  • Fe₂(SO₄)₃ — сульфат железа(III).

Качественные реакции:

  • На Fe²⁺: с красной кровяной солью K₃[Fe(CN)₆] — синий осадок турнбулевой сини.
  • На Fe³⁺: с жёлтой кровяной солью K₄[Fe(CN)₆] — синий осадок берлинской лазури.
  • На Fe³⁺: с роданидом калия KSCN — кроваво-красное окрашивание.

Применение:

  • Чёрная металлургия — производство стали и чугуна.
  • Строительство, машиностроение.
  • Fe₂O₃ — красный пигмент для краски.
  • Fe₃O₄ — магнитные материалы.
  • FeSO₄ — в медицине (при анемии).
Пример

Решение.

2Fe + 3Cl₂ → 2FeCl₃
Fe + CuSO₄ → FeSO₄ + Cu↓
2Fe(OH)₃ → Fe₂O₃ + 3H₂O

§8 Коррозия металлов и способы защиты от неё
Коррозия Самопроизвольное разрушение металлов и сплавов под действием окружающей среды (кислорода, воды, кислот, солей).

Виды коррозии:

  • Химическая — в сухих газах или неэлектролитах (при высоких температурах).
  • Электрохимическая — в присутствии электролита (влажный воздух, растворы солей). Более частая и опасная.

Электрохимическая коррозия: происходит, когда два разных металла находятся в контакте в присутствии электролита. Более активный металл окисляется (анод), менее активный восстанавливается (катод).

Пример — коррозия железа:

Fe → Fe²⁺ + 2e⁻ (анод, окисление)
O₂ + 2H₂O + 4e⁻ → 4OH⁻ (катод, восстановление)
4Fe(OH)₂ + O₂ + 2H₂O → 4Fe(OH)₃ → Fe₂O₃·nH₂O (ржавчина)

Факторы, ускоряющие коррозию:

  • Повышенная влажность и температура.
  • Наличие солей (морская вода, антигололёдные реагенты).
  • Кислая среда (кислотные дожди).
  • Контакт разных металлов (гальваническая пара).
  • Механические нагрузки (трещины, царапины).

Способы защиты от коррозии:

1. Нанесение защитных покрытий:

  • Неметаллические: лаки, краски, эмали, смазки.
  • Металлические: хромирование, никелирование, цинкование, лужение (Sn).

2. Легирование — добавление в сплав компонентов (Cr, Ni, Ti), повышающих коррозионную стойкость. Пример: нержавеющая сталь (Fe + Cr + Ni).

3. Протекторная (жертвенная) защита — к защищаемой конструкции крепят более активный металл (Zn, Mg), который и окисляется вместо неё:

Zn → Zn²⁺ + 2e⁻ (вместо Fe)

Применяется для трубопроводов, корпусов судов, подземных сооружений.

4. Изменение среды — добавление ингибиторов коррозии, удаление кислорода, осушение воздуха.

5. Электрохимическая защита — катодная (подключение к отрицательному полюсу источника тока) и анодная.

Пример
Задание. Почему железные изделия, покрытые цинком, менее подвержены коррозии, чем покрытые оловом (при повреждении покрытия)?
Решение. Цинк активнее железа (Zn левее в ряду активности) — при повреждении он окисляется первым, защищая железо (протекторная защита). Олово менее активно, чем железо, поэтому при повреждении корродировать начнёт железо.
Вывод: Zn защищает, Sn — нет (при повреждении даже ускоряет коррозию).

§9 Металлы в природе. Понятие о металлургии

Формы нахождения металлов в природе:

  • Самородные металлы — Au, Ag, Pt, реже Cu, Hg (не реагируют с кислородом).
  • Оксиды и гидроксиды — Fe₂O₃, Fe₃O₄, Al₂O₃, MnO₂, SnO₂.
  • Сульфиды — FeS₂, PbS, ZnS, HgS, CuFeS₂.
  • Карбонаты — CaCO₃, MgCO₃, FeCO₃.
  • Сульфаты — CaSO₄·2H₂O, BaSO₄.
  • Хлориды — NaCl, KCl, MgCl₂.
  • Силикаты и алюмосиликаты — основа земной коры.
  • Фосфаты — Ca₃(PO₄)₂, апатиты.
Металлургия Наука и отрасль промышленности, занимающаяся получением металлов из природного сырья (руд, минералов).

Основные способы получения металлов:

1. Пирометаллургия — восстановление при высоких температурах:

  • Углём (коксом):
    Fe₂O₃ + 3C → 2Fe + 3CO↑
  • Оксидом углерода(II):
    Fe₂O₃ + 3CO → 2Fe + 3CO₂↑
  • Водородом:
    WO₃ + 3H₂ → W + 3H₂O
  • Более активным металлом (металлотермия):
    2Al + Fe₂O₃ → Al₂O₃ + 2Fe (алюминотермия)

2. Гидрометаллургия — восстановление из растворов:

  1. Перевод нерастворимого соединения в раствор (обработкой кислотой или щёлочью).
  2. Вытеснение металла более активным или электролизом.
CuO + H₂SO₄ → CuSO₄ + H₂O
CuSO₄ + Fe → FeSO₄ + Cu↓

3. Электрометаллургия — электролиз расплавов или растворов:

2NaCl → 2Na + Cl₂↑ (электролиз расплава)
2Al₂O₃ → 4Al + 3O₂↑ (электролиз в криолите)

Применяется для активных металлов (Na, K, Ca, Mg, Al).

Значение металлургии:

  • Чёрная металлургия — производство стали и чугуна.
  • Цветная металлургия — производство Cu, Al, Zn, Pb, Ni и др.
  • Основа машиностроения, строительства, энергетики.

Проблемы металлургии:

  • Высокая энергоёмкость.
  • Загрязнение окружающей среды (выбросы, шлаки).
  • Истощение рудных запасов.

Пути решения: переработка отходов, использование вторичного сырья, внедрение безотходных технологий, очистка выбросов.

Пример
Задание. Как получить железо из Fe₂O₃ тремя способами?
Решение.
1) Fe₂O₃ + 3C → 2Fe + 3CO↑
2) Fe₂O₃ + 3CO → 2Fe + 3CO₂↑
3) Fe₂O₃ + 2Al → Al₂O₃ + 2Fe

§2 Охрана окружающей среды от химического загрязнения

Хозяйственная деятельность человека приводит к загрязнению атмосферы, гидросферы и литосферы. Это одна из главных экологических проблем современности.

Загрязнение окружающей среды Поступление в природу вредных веществ (загрязнителей), которые нарушают естественные процессы и наносят вред живым организмам.

Основные источники загрязнения:

  • Промышленность — выбросы заводов (SO₂, NO₂, CO, пыль, тяжёлые металлы).
  • Транспорт — выхлопные газы (CO, NOₓ, углеводороды, сажа).
  • Сельское хозяйство — пестициды, удобрения, отходы животноводства.
  • Энергетика — выбросы ТЭЦ, радиоактивные отходы АЭС.
  • Бытовые отходы — пластик, стекло, металлы, органика.

Основные виды загрязнений:

ВидЗагрязнителиПоследствия
АтмосферноеSO₂, NO₂, CO, пыль, фреоныКислотные дожди, смог, парниковый эффект, разрушение озонового слоя
ВодноеНефть, тяжёлые металлы, ПАВ, пестицидыГибель рыбы, отравление воды, цветение водоёмов
ПочвенноеПестициды, тяжёлые металлы, отходыСнижение плодородия, накопление ядов в растениях
РадиоактивноеРадиоактивные отходыОблучение, мутации, рак

Экологические проблемы:

  • Парниковый эффект — накопление CO₂, CH₄, N₂O → повышение температуры.
  • Кислотные дожди — SO₂ и NO₂ + H₂O → H₂SO₄, HNO₃. Разрушают здания, губят растения и рыб.
  • Разрушение озонового слоя — фреоны (CFC) разрушают O₃ в стратосфере.
  • Загрязнение Мирового океана — нефть, пластик, промышленные стоки.
  • Накопление бытовых отходов — пластик разлагается сотни лет.

Меры по охране окружающей среды:

1. Технологические:

  • Создание безотходных и малоотходных производств.
  • Очистка промышленных выбросов и сточных вод (фильтры, отстойники, каталитические нейтрализаторы).
  • Переход на возобновляемые источники энергии (солнце, ветер, вода).
  • Использование вторичного сырья (переработка).

2. Правовые:

  • Законы об охране природы.
  • Штрафы за загрязнение.
  • Создание заповедников и национальных парков.

3. Воспитательные:

  • Экологическое образование и просвещение.
  • Формирование ответственного отношения к природе.
  • Раздельный сбор мусора.

Химия в защите природы:

  • Разработка новых катализаторов для нейтрализации вредных выбросов.
  • Создание биоразлагаемых полимеров.
  • Очистка воды и воздуха с помощью современных материалов.
  • Мониторинг загрязнений (анализ проб).
Пример
Задание. Какие химические реакции вызывают образование кислотных дождей?
Решение.
1) При сжигании топлива: S + O₂ → SO₂; N₂ + O₂ → 2NO (при высокой t°).
2) Дальнейшее окисление: 2SO₂ + O₂ → 2SO₃; 2NO + O₂ → 2NO₂.
3) Растворение в воде: SO₃ + H₂O → H₂SO₄; 3NO₂ + H₂O → 2HNO₃ + NO.
Образовавшиеся кислоты выпадают с дождём — кислотные дожди.

4. Типы кристаллических решёток:

  • Ионная: ионы. Вещества твёрдые, тугоплавкие, растворы проводят ток (NaCl, KOH).
  • Атомная: атомы. Очень твёрдые, тугоплавкие (алмаз, Si, SiO₂, SiC).
  • Молекулярная: молекулы. Легкоплавкие, летучие (H₂O, CO₂, O₂, сахар).
  • Металлическая: ионы металла + свободные электроны. Металлы (Fe, Cu, Al).

5. Основные формулы:

  • Количество вещества: n = m / M (моль)
  • Число частиц: N = n · Nₐ (Nₐ = 6,02·10²³)
  • Молярный объём газа: V = n · Vₘ (Vₘ = 22,4 л/моль при н.у.)
  • Массовая доля элемента: ω(Э) = (A·n) / M × 100%
  • Массовая доля вещества в растворе: ω = m(в-ва) / m(р-ра) × 100%
Пример
Задание. Найдите массовую долю кислорода в H₂SO₄.
Решение.
M(H₂SO₄) = 2·1 + 32 + 4·16 = 98 г/моль.
ω(O) = (4·16) / 98 × 100% ≈ 65,3 %.
§2 Химические реакции

1. Типы реакций по числу веществ:

  • Соединения: A + B → AB (2H₂ + O₂ → 2H₂O)
  • Разложения: AB → A + B (2H₂O₂ → 2H₂O + O₂↑)
  • Замещения: A + BC → AC + B (Fe + CuSO₄ → FeSO₄ + Cu)
  • Обмена: AB + CD → AD + CB (NaOH + HCl → NaCl + H₂O)

2. Правило Бертолле: реакции ионного обмена идут до конца, если образуется осадок, газ или вода (слабый электролит).

3. Окислительно-восстановительные реакции (ОВР):

  • Окисление — отдача электронов (степень окисления повышается).
  • Восстановление — принятие электронов (степень окисления понижается).
  • Окислитель — принимает электроны, сам восстанавливается.
  • Восстановитель — отдаёт электроны, сам окисляется.

4. Электролитическая диссоциация:

  • Кислоты → H⁺ + кислотный остаток
  • Основания → Me + OH⁻
  • Соли → Me + кислотный остаток

5. Скорость реакции:

  • Зависит от: природы веществ, концентрации, температуры, площади поверхности, катализатора, давления (для газов).
  • Правило Вант-Гоффа: повышение t° на 10 °C ускоряет реакцию в 2–4 раза.
Пример
Задание. Определите тип реакции: Zn + 2HCl → ZnCl₂ + H₂↑.
Решение.
— По числу веществ: замещение.
— По тепловому эффекту: экзотермическая.
— По обратимости: необратимая.
— По степеням окисления: ОВР (Zn⁰ → Zn²⁺, H⁺ → H⁰).
§3 Основы неорганической химии

1. Свойства оксидов:

  • Основные оксиды: + H₂O (для щелочных/щелочноземельных) → основание; + кислота → соль + вода; + кислотный оксид → соль.
  • Кислотные оксиды: + H₂O → кислота; + основание → соль + вода; + основной оксид → соль.
  • Амфотерные: реагируют и с кислотами, и со щелочами.

2. Свойства кислот:

  • + металл до H₂ → соль + H₂↑
  • + основной оксид → соль + H₂O
  • + основание → соль + H₂O (нейтрализация)
  • + соль → новая соль + новая кислота (если осадок или газ)

3. Свойства оснований:

  • + кислота → соль + H₂O
  • + кислотный оксид → соль + H₂O
  • + соль → новая соль + новое основание (если осадок)
  • Нерастворимые: разлагаются при нагревании → оксид + H₂O

4. Свойства солей:

  • + металл (более активный) → новая соль + металл
  • + кислота → новая соль + новая кислота (если осадок или газ)
  • + щёлочь → новая соль + новое основание (если осадок или газ)
  • + соль → две новые соли (если осадок)

5. Генетическая связь:

Металл → Основный оксид → Основание → Соль
Неметалл → Кислотный оксид → Кислота → Соль

6. Гидролиз солей:
