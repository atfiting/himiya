§1 Классификация неорганических соединений

Все вещества делятся на простые (O₂, Fe, S) и сложные (H₂O, NaCl, H₂SO₄). Среди сложных неорганических выделяют четыре важнейших класса: оксиды, основания, кислоты, соли.

Оксиды Сложные вещества из двух элементов, один из которых — кислород в степени окисления −2.
Примеры: Na₂O, CaO, Al₂O₃, CO₂, SO₃, Fe₂O₃.

Оксиды делятся на:

  • Основные — оксиды металлов +1, +2 (Na₂O, CaO, MgO, CuO).
  • Кислотные — оксиды неметаллов и металлов с высокой с.о. (CO₂, SO₃, P₂O₅).
  • Амфотерные — проявляют и кислотные, и основные свойства (Al₂O₃, ZnO, BeO, Cr₂O₃).
  • Несолеобразующие — не образуют солей (CO, NO, N₂O, SiO).
Основания Сложные вещества из иона металла и одной или нескольких гидроксид-групп OH⁻.
Общая формула: Me(OH)ₙ.
Примеры: NaOH, KOH, Ca(OH)₂, Fe(OH)₃.

Основания делятся на:

  • Растворимые (щёлочи): NaOH, KOH, LiOH, Ca(OH)₂, Ba(OH)₂.
  • Нерастворимые: Cu(OH)₂, Fe(OH)₃, Al(OH)₃, Mg(OH)₂.
  • Амфотерные: Zn(OH)₂, Al(OH)₃, Be(OH)₂, Cr(OH)₃.
Кислоты Сложные вещества из атомов водорода, способных замещаться металлом, и кислотного остатка.
Примеры: HCl, H₂SO₄, HNO₃, H₃PO₄, CH₃COOH.

Кислоты классифицируют:

  • По основности: одноосновные (HCl, HNO₃), двухосновные (H₂SO₄, H₂S), трёхосновные (H₃PO₄).
  • По кислороду: кислородсодержащие (H₂SO₄, HNO₃), бескислородные (HCl, H₂S).
  • По силе: сильные (HCl, H₂SO₄, HNO₃), средние (H₃PO₄, HF), слабые (H₂CO₃, H₂S, CH₃COOH).
Соли Сложные вещества из иона металла (или NH₄⁺) и аниона кислотного остатка.
Примеры: NaCl, K₂SO₄, CaCO₃, Cu(NO₃)₂.

Соли делятся на: средние (NaCl, K₂SO₄), кислые (NaHCO₃, KHSO₄), основные (Cu₂(OH)₂CO₃), двойные (KAl(SO₄)₂), комплексные (K₄[Fe(CN)₆]).

§2 Классификация химических реакций

1. По числу и составу веществ:

  • Соединения: A + B → AB. Пример: 2H₂ + O₂ → 2H₂O.
  • Разложения: AB → A + B. Пример: 2H₂O₂ → 2H₂O + O₂↑.
  • Замещения: A + BC → AC + B. Пример: Fe + CuSO₄ → FeSO₄ + Cu.
  • Обмена: AB + CD → AD + CB. Пример: NaOH + HCl → NaCl + H₂O.

2. По тепловому эффекту:

  • Экзотермические (+Q): C + O₂ → CO₂ + Q.
  • Эндотермические (−Q): CaCO₃ → CaO + CO₂ − Q.

3. По обратимости:

  • Необратимые (→): BaCl₂ + H₂SO₄ → BaSO₄↓ + 2HCl.
  • Обратимые (⇄): N₂ + 3H₂ ⇄ 2NH₃.

4. По изменению степеней окисления:

  • ОВР: Zn⁰ + Cu²⁺SO₄ → Zn²⁺SO₄ + Cu⁰.
  • Не ОВР: NaOH + HCl → NaCl + H₂O.

5. По агрегатному состоянию: гомогенные, гетерогенные.

6. По катализатору: каталитические (N₂ + 3H₂ с Fe), некаталитические.

7. По направлению: прямые, обратные.

Пример
Задание. Охарактеризуйте 2KClO₃ → 2KCl + 3O₂↑ по всем признакам.
Решение. Разложение, эндотермическая, необратимая, ОВР (Cl⁺⁵ → Cl⁻¹, O⁻² → O⁰), гетерогенная, каталитическая (MnO₂).
Задача
1. Определите тип: Fe + 2HCl → FeCl₂ + H₂↑.
2. Охарактеризуйте CaCO₃ → CaO + CO₂↑ по всем признакам.
3. Какая из реакций — ОВР: NaOH + HCl → NaCl + H₂O или Zn + 2HCl → ZnCl₂ + H₂↑?
§3 Скорость химических реакций. Катализ
Скорость химической реакции Изменение концентрации одного из реагирующих веществ за единицу времени.
Формула: υ = ΔC / Δt (моль/(л·с)).

Факторы, влияющие на скорость:

1. Природа реагирующих веществ. Активные вещества реагируют быстрее.

2. Концентрация. Закон действующих масс:

Для aA + bB → продукты: υ = k·[A]ᵃ·[B]ᵇ

3. Температура. Правило Вант-Гоффа:

υ₂ / υ₁ = γ^(Δt / 10)

где γ — температурный коэффициент (2–4).

4. Площадь поверхности. Измельчение и перемешивание ускоряют гетерогенные реакции.

5. Катализатор. Ускоряет реакцию, но не расходуется.

6. Давление. Для газов — чем выше давление, тем выше скорость.

7. Свет, ток, излучение. Некоторые реакции идут только под их действием.

Катализ Явление изменения скорости реакции под действием катализатора.
Катализатор — ускоряет реакцию, но не расходуется.
Ингибитор — замедляет реакцию.

Виды катализа: гомогенный, гетерогенный, ферментативный.

Важнейшие катализаторы:

РеакцияКатализатор
N₂ + 3H₂ → 2NH₃Fe
2SO₂ + O₂ → 2SO₃V₂O₅
2KClO₃ → 2KCl + 3O₂MnO₂
CₙH₂ₙ + H₂ → CₙH₂ₙ₊₂Ni, Pt, Pd
Пример 1
Задание. Как изменится скорость реакции 2SO₂ + O₂ → 2SO₃ при увеличении давления в 3 раза?
Решение. υ₁ = k·[SO₂]²·[O₂]; υ₂ = k·(3[SO₂])²·(3[O₂]) = 27·υ₁. Ответ: в 27 раз.
Пример 2
Задание. Как изменится скорость реакции при повышении t° с 20 °C до 40 °C, если γ = 3?
Решение. Δt = 20 °C. υ₂/υ₁ = 3^(20/10) = 9. Ответ: в 9 раз.
Задача
1. Как изменится скорость A + 2B → C при увеличении [A] в 2 раза?
2. Во сколько раз увеличится скорость при нагревании на 30 °C, если γ = 2?
3. Почему порошок реагирует быстрее куска?

§1 Электролитическая диссоциация

Многие вещества в воде начинают проводить электрический ток — их растворы становятся проводниками второго рода. Это возможно только потому, что в растворе появляются свободные ионы.

Электролитическая диссоциация Процесс распада молекул электролита на ионы (катионы и анионы) при растворении в воде или при расплавлении.

Примеры:

NaCl → Na⁺ + Cl⁻
KOH → K⁺ + OH⁻
HNO₃ → H⁺ + NO₃⁻

Электролиты — вещества, распадающиеся на ионы:

  • Растворимые соли: NaCl, KNO₃, CuSO₄, Na₂CO₃, NH₄Cl.
  • Щёлочи: NaOH, KOH, LiOH, Ca(OH)₂, Ba(OH)₂.
  • Кислоты: HCl, H₂SO₄, HNO₃, H₃PO₄, CH₃COOH.

Неэлектролиты — не распадаются на ионы:

  • Сахар (C₁₂H₂₂O₁₁), глюкоза (C₆H₁₂O₆), спирт (C₂H₅OH), ацетон.
  • Простые вещества (O₂, H₂, N₂, Cl₂), оксиды (CO₂, SiO₂, CaO).
  • Нерастворимые соли и основания (CaCO₃, BaSO₄, Cu(OH)₂).

Механизм диссоциации:

  • Ионная связь (соли, щёлочи): молекулы воды притягиваются к ионам кристалла и «растаскивают» его, окружая ионы гидратной оболочкой.
  • Ковалентная полярная связь (кислоты): молекулы воды поляризуют связь, превращая её в ионную.

💡 Твёрдый NaCl не проводит ток — ионы «заперты» в кристалле. Расплав или раствор — проводят: ионы свободны.

§2 Основные положения теории электролитической диссоциации

Теория ТЭД сформулирована шведским учёным Сванте Аррениусом в 1887 году.

  • 1. Электролиты в воде распадаются на ионы — катионы и анионы.
  • 2. Причина диссоциации — взаимодействие молекул электролита с молекулами воды (гидратация).
  • 3. Ионы в растворе гидратированы (окружены молекулами воды).
  • 4. Диссоциация — обратимый процесс: наряду с распадом идёт ассоциация.
  • 5. Сильные электролиты диссоциируют полностью, слабые — частично.
  • 6. Химические свойства растворов определяются свойствами ионов.
Степень диссоциации (α) Отношение числа молекул, распавшихся на ионы, к общему числу растворённых молекул.
Формула: α = N(распавшихся) / N(общих) × 100%
КатегорияαПримеры
Сильные> 30%HCl, H₂SO₄, HNO₃, NaOH, KOH, растворимые соли
Средние3–30%H₃PO₄, HF, H₂SO₃, HNO₂
Слабые< 3%CH₃COOH, H₂CO₃, H₂S, NH₄OH, вода

Правила записи уравнений диссоциации:

  • Формула слева, ионы справа.
  • Число атомов слева и справа совпадает.
  • Сумма зарядов ионов справа равна нулю.
  • Многоосновные кислоты диссоциируют ступенчато.

Примеры:

Al₂(SO₄)₃ → 2Al³⁺ + 3SO₄²⁻
H₃PO₄: 1) H₃PO₄ ⇄ H⁺ + H₂PO₄⁻; 2) H₂PO₄⁻ ⇄ H⁺ + HPO₄²⁻; 3) HPO₄²⁻ ⇄ H⁺ + PO₄³⁻
Пример
Задание. В растворе из 200 молекул уксусной кислоты распалось 6. Найдите α.
Решение. α = 6/200 × 100% = 3%. Уксусная кислота — слабый электролит.

§3 Химические свойства кислот как электролитов

Кислоты — электролиты, при диссоциации образующие только катионы H⁺ и анионы кислотного остатка.

HCl → H⁺ + Cl⁻
H₂SO₄ → 2H⁺ + SO₄²⁻

Индикаторы: лакмус красный, метилоранж розовый, фенолфталеин бесцветный.

Свойство 1. Диссоциация с образованием H⁺.

Свойство 2. С металлами (до H₂ в ряду активности):

Zn + 2HCl → ZnCl₂ + H₂↑
Ряд: Li K Ba Ca Na Mg Al Zn Cr Fe Ni Sn Pb (H₂) Cu Hg Ag Pt Au

Свойство 3. С основными оксидами:

CuO + H₂SO₄ → CuSO₄ + H₂O

Свойство 4. С основаниями (нейтрализация):

NaOH + HCl → NaCl + H₂O

Свойство 5. С солями (если осадок, газ или слабый электролит):

CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑
AgNO₃ + HCl → AgCl↓ + HNO₃
Пример
Задание. Напишите реакции HCl с Zn, CuO, NaOH, AgNO₃.
Решение. 1) Zn + 2HCl → ZnCl₂ + H₂↑; 2) CuO + 2HCl → CuCl₂ + H₂O; 3) NaOH + HCl → NaCl + H₂O; 4) AgNO₃ + HCl → AgCl↓ + HNO₃.

§4 Химические свойства оснований как электролитов

Основания — электролиты, при диссоциации образующие только ионы OH⁻ и катионы металла (или NH₄⁺).

NaOH → Na⁺ + OH⁻
Ca(OH)₂ → Ca²⁺ + 2OH⁻

Классификация:

  • Растворимые (щёлочи): NaOH, KOH, LiOH, Ca(OH)₂, Ba(OH)₂.
  • Нерастворимые: Cu(OH)₂, Fe(OH)₃, Al(OH)₃, Mg(OH)₂.
  • Амфотерные: Zn(OH)₂, Al(OH)₃, Be(OH)₂, Cr(OH)₃.

Индикаторы: лакмус синий, метилоранж жёлтый, фенолфталеин малиновый.

Свойство 1. Диссоциация с образованием OH⁻.

Свойство 2. С кислотами (нейтрализация):

KOH + HNO₃ → KNO₃ + H₂O

Свойство 3. С кислотными оксидами:

2NaOH + CO₂ → Na₂CO₃ + H₂O
Ca(OH)₂ + CO₂ → CaCO₃↓ + H₂O (помутнение известковой воды)

Свойство 4. С солями:

2NaOH + CuSO₄ → Cu(OH)₂↓ + Na₂SO₄
NH₄Cl + NaOH → NaCl + NH₃↑ + H₂O

Свойство 5. Разложение нерастворимых при нагревании:

Cu(OH)₂ →t°→ CuO + H₂O

Амфотерность:

Al(OH)₃ + 3HCl → AlCl₃ + 3H₂O (как основание)
Al(OH)₃ + NaOH → Na[Al(OH)₄] (как кислота)

Решение. 1) NaOH + HCl → NaCl + H₂O; 2) 2NaOH + CO₂ → Na₂CO₃ + H₂O; 3) 2NaOH + CuSO₄ → Cu(OH)₂↓ + Na₂SO₄.

§5 Химические свойства солей как электролитов

Соли — электролиты, при диссоциации образующие катионы металла (или NH₄⁺) и анионы кислотного остатка.

NaCl → Na⁺ + Cl⁻
Al₂(SO₄)₃ → 2Al³⁺ + 3SO₄²⁻

Свойство 1. С металлами (более активный вытесняет менее активный):

Fe + CuSO₄ → FeSO₄ + Cu↓
Cu + 2AgNO₃ → Cu(NO₃)₂ + 2Ag↓

⚠ Na, K, Ca с растворами солей так не реагируют — сначала взаимодействуют с водой.

Свойство 2. С кислотами:

BaCl₂ + H₂SO₄ → BaSO₄↓ + 2HCl
Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑

Свойство 3. С основаниями:

CuSO₄ + 2NaOH → Cu(OH)₂↓ + Na₂SO₄

Свойство 4. С солями:

AgNO₃ + NaCl → AgCl↓ + NaNO₃

Свойство 5. Разложение при нагревании:

CaCO₃ →t°→ CaO + CO₂↑
Правило Бертолле Реакции ионного обмена идут до конца, если образуется осадок, газ или слабый электролит (вода, слабая кислота, слабое основание).

Частые осадки: AgCl (белый), BaSO₄ (белый), CaCO₃ (белый), Cu(OH)₂ (голубой), Fe(OH)₃ (бурый), PbI₂ (жёлтый).

Как писать ионные уравнения:

Молекулярное: BaCl₂ + Na₂SO₄ → BaSO₄↓ + 2NaCl
Полное: Ba²⁺ + 2Cl⁻ + 2Na⁺ + SO₄²⁻ → BaSO₄↓ + 2Na⁺ + 2Cl⁻
Сокращённое: Ba²⁺ + SO₄²⁻ → BaSO₄↓
Пример
Задание. Напишите все формы уравнения CuSO₄ + NaOH.
Решение. Молекулярное: CuSO₄ + 2NaOH → Cu(OH)₂↓ + Na₂SO₄. Полное: Cu²⁺ + SO₄²⁻ + 2Na⁺ + 2OH⁻ → Cu(OH)₂↓ + 2Na⁺ + SO₄²⁻. Сокращённое: Cu²⁺ + 2OH⁻ → Cu(OH)₂↓.

§6 Гидролиз солей
Гидролиз солей Обменная реакция между ионами соли и молекулами воды, приводящая к образованию слабого электролита и изменению кислотности среды.

Вода — слабый электролит: H₂O ⇄ H⁺ + OH⁻. Ионы соли могут связывать H⁺ или OH⁻ в слабый электролит, изменяя pH.

Четыре типа солей:

ТипГидролизpHПример
Сильная + сильноеНе гидролизуется= 7NaCl, KNO₃
Слабая + сильноеПо аниону> 7Na₂CO₃, CH₃COONa
Сильная + слабоеПо катиону< 7NH₄Cl, CuCl₂
Слабая + слабоеПо катиону и анионуЗависитCH₃COONH₄

Гидролиз по аниону:

CO₃²⁻ + H₂O ⇄ HCO₃⁻ + OH⁻ (щелочная среда)
Na₂CO₃ + H₂O ⇄ NaHCO₃ + NaOH

Гидролиз по катиону:

Cu²⁺ + H₂O ⇄ CuOH⁺ + H⁺ (кислая среда)
CuCl₂ + H₂O ⇄ CuOHCl + HCl

Совместный гидролиз:

CH₃COO⁻ + NH₄⁺ + H₂O ⇄ CH₃COOH + NH₄OH

Правила:

  • Усиливается при нагревании и разбавлении.
  • Подавляется добавлением кислоты (по аниону) или щёлочи (по катиону).
  • Необратимый гидролиз — если образуется и слабая кислота, и слабое основание, и они выводятся из реакции: Al₂S₃ + 6H₂O → 2Al(OH)₃↓ + 3H₂S↑.
Пример
Задание. Определите среду растворов NaCl, Na₂CO₃, NH₄Cl.
Решение. NaCl — нейтральная (pH = 7). Na₂CO₃ — щелочная (pH > 7, гидролиз по аниону). NH₄Cl — кислая (pH < 7, гидролиз по катиону).
Задача
1. Определите среду: K₂SO₄, K₂CO₃, CuCl₂, NH₄NO₃.
2. Напишите уравнения гидролиза: Na₂S, AlCl₃, CH₃COONH₄.
3. Почему раствор Na₂CO₃ мылкий на ощупь?

§1 Общая характеристика неметаллов

Из 118 элементов около 90 — металлы, остальные — неметаллы. Неметаллы расположены в правой верхней части ПСХЭ.

Неметаллы Химические элементы, атомы которых преимущественно принимают электроны. На внешнем уровне 4–7 электронов (у H и B — 1 и 3).

Положение в ПСХЭ:

  • VIIA: F, Cl, Br, I — галогены.
  • VIA: O, S, Se, Te — халькогены.
  • VA: N, P, As — пниктогены.
  • IVA: C, Si (неметаллы), Ge, Sn, Pb (металлы).
  • IIIA: B — неметалл.
  • IA: H — неметалл.

Физические свойства:

  • Твёрдые (S, P, C), жидкий (Br₂), газообразные (H₂, O₂, N₂, Cl₂).
  • Плохо проводят ток (исключение — графит).
  • Хрупкие, разные t° пл.

Химические свойства:

  • С металлами: 2Na + Cl₂ → 2NaCl.
  • С водородом: H₂ + Cl₂ → 2HCl.
  • С кислородом: S + O₂ → SO₂.
Электроотрицательность Способность атома притягивать электроны. Ряд: F > O > N ≈ Cl > Br > I > S > C > P > H > металлы.
Пример
Задание. Расположите F, O, N, Cl, S, C по усилению окислительных свойств.
Решение. C < S < N < Cl < O < F.
Задача
1. В каких группах ПСХЭ расположены неметаллы?
2. Сколько электронов на внешнем уровне F, S, N, C?
3. Напишите: Na + Cl₂, H₂ + F₂, S + O₂.

Галогены — элементы VIIA: F, Cl, Br, I, At. На внешнем уровне 7 электронов, до октета не хватает 1 → сильные окислители.

Простые вещества: F₂ — бледно-жёлтый газ, Cl₂ — жёлто-зелёный газ, Br₂ — тёмно-бурая жидкость, I₂ — тёмно-фиолетовые кристаллы (возгоняется).

§4 Изучение свойств соляной кислоты

HCl — водный раствор хлороводорода. Сильная одноосновная кислота, входит в состав желудочного сока.

Физические свойства: бесцветная жидкость с резким запахом, концентрированная «дымит» на воздухе, хорошо растворяется в воде (до 40 %).

Химические свойства (общие для кислот):

HCl → H⁺ + Cl⁻ (диссоциация)
Zn + 2HCl → ZnCl₂ + H₂↑ (с металлами до H₂)
CuO + 2HCl → CuCl₂ + H₂O (с основными оксидами)
NaOH + HCl → NaCl + H₂O (нейтрализация)
Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑ (с солями)
AgNO₃ + HCl → AgCl↓ + HNO₃ (качественная реакция)

Качественная реакция на Cl⁻: белый творожистый осадок AgCl, нерастворимый в HNO₃.

Применение: травление металлов, получение хлоридов, хлора, лекарств, регулирование pH.

⚠ ТБ: работать в перчатках и очках, при попадании на кожу — промыть водой.

Сверху вниз: радиус ↑, ЭО ↓, окислительные свойства ↓.

§6 Сера, сероводород и сульфиды

Сера — жёлтое кристаллическое вещество. В природе: самородная, сульфиды (FeS₂, PbS, ZnS), сульфаты (CaSO₄·2H₂O).

Химические свойства серы:

Fe + S → FeS (с металлами, S — окислитель)
H₂ + S → H₂S
S + O₂ → SO₂ (с кислородом, S — восстановитель)

Сероводород H₂S — газ с запахом тухлых яиц, ядовит. Раствор — слабая двухосновная кислота:

H₂S ⇄ H⁺ + HS⁻ ⇄ 2H⁺ + S²⁻

Свойства H₂S:

H₂S + 2NaOH → Na₂S + 2H₂O
H₂S + CuSO₄ → CuS↓ + H₂SO₄
2H₂S + 3O₂ → 2SO₂ + 2H₂O (избыток O₂)
2H₂S + O₂ → 2S + 2H₂O (недостаток O₂)

Сульфиды — соли H₂S. Многие нерастворимы: ZnS (белый), FeS (чёрный), CuS (чёрный), PbS (чёрный), HgS (красный).

💡 Качественная реакция на S²⁻: с Pb(NO₃)₂ → чёрный осадок PbS.

Пример
Задание. Напишите: Fe + S; H₂S + NaOH; CuSO₄ + H₂S.
Решение. 1) Fe + S → FeS; 2) H₂S + 2NaOH → Na₂S + 2H₂O; 3) CuSO₄ + H₂S → CuS↓ + H₂SO₄.
Задача

2. Как обнаружить S²⁻?
3. Почему сероводород опасен?
§7 Кислородные соединения серы

Два важнейших оксида: SO₂ (+4) и SO₃ (+6).

SO₂ — сернистый газ, бесцветный, с резким запахом, ядовит. Причина кислотных дождей.

SO₂ + H₂O ⇄ H₂SO₃
SO₂ + 2NaOH → Na₂SO₃ + H₂O
2SO₂ + O₂ ⇄ 2SO₃ (кат., t°)

SO₃ — серный ангидрид, бесцветная жидкость, дымит на воздухе.

SO₃ + H₂O → H₂SO₄
SO₃ + 2NaOH → Na₂SO₄ + H₂O

Сернистая кислота H₂SO₃ — слабая, неустойчивая. Соли — сульфиты (Na₂SO₃) и гидросульфиты (NaHSO₃).

Серная кислота H₂SO₄ — сильная. Соли — сульфаты (Na₂SO₄) и гидросульфаты (NaHSO₄).

Важнейшие сульфаты: BaSO₄ (нерастворим, для рентгена), CaSO₄·2H₂O (гипс), CuSO₄·5H₂O (медный купорос).

Качественная реакция на SO₄²⁻:

BaCl₂ + Na₂SO₄ → BaSO₄↓ (белый) + 2NaCl

💡 Осадок BaSO₄ не растворяется в кислотах.

Пример
Задание. Как отличить сульфит от сульфата?
Решение. Добавить BaCl₂ и HCl: сульфит даёт BaSO₃, который растворяется в HCl с выделением SO₂; сульфат даёт BaSO₄, нерастворимый.

2. Как обнаружить SO₄²⁻?
3. Чем опасны кислотные дожди?
§8 Изучение свойств серной кислоты

H₂SO₄ — сильная двухосновная кислота. Мировое производство — показатель развития химической промышленности.

Физические свойства: бесцветная маслянистая жидкость (ρ = 1,84 г/см³), гигроскопична, смешивается с водой с выделением большого количества теплоты, обугливает органику.

⚠ Правило: лить кислоту в воду, а не наоборот!

Диссоциация:

H₂SO₄ → H⁺ + HSO₄⁻ (1-я ступень, сильная)
HSO₄⁻ ⇄ H⁺ + SO₄²⁻ (2-я ступень, слабая)

Свойства разбавленной H₂SO₄ (общие свойства кислот):

Zn + H₂SO₄ → ZnSO₄ + H₂↑
CuO + H₂SO₄ → CuSO₄ + H₂O
2NaOH + H₂SO₄ → Na₂SO₄ + 2H₂O
BaCl₂ + H₂SO₄ → BaSO₄↓ + 2HCl

Особые свойства концентрированной H₂SO₄:

Cu + 2H₂SO₄(конц.) → CuSO₄ + SO₂↑ + 2H₂O
C + 2H₂SO₄(конц.) → CO₂↑ + 2SO₂↑ + 2H₂O

Пассивирует Al, Fe, Cr на холоде. Используется как осушитель.

Промышленное получение (контактный способ):

1) 4FeS₂ + 11O₂ → 2Fe₂O₃ + 8SO₂
2) 2SO₂ + O₂ ⇄ 2SO₃ (кат. V₂O₅, 450 °C)
3) SO₃ + H₂O → H₂SO₄ (или растворение в H₂SO₄ → олеум)

Применение: удобрения, аккумуляторы, очистка нефти, осушка газов, получение других кислот.

⚠ ТБ: едкое вещество, работать в перчатках и очках, при попадании — промыть водой и обработать содой.

Пример
Задание. Напишите 5 уравнений реакций разб. H₂SO₄.
Решение. 1) Zn + H₂SO₄ → ZnSO₄ + H₂↑; 2) CuO + H₂SO₄ → CuSO₄ + H₂O; 3) 2NaOH + H₂SO₄ → Na₂SO₄ + 2H₂O; 4) BaCl₂ + H₂SO₄ → BaSO₄↓ + 2HCl; 5) CaCO₃ + H₂SO₄ → CaSO₄ + H₂O + CO₂↑.

§9 Общая характеристика элементов VA группы. Азот

Пниктогены — элементы VA: N, P, As, Sb, Bi. На внешнем уровне 5 электронов (ns²np³).

Азот N₂ — газ без цвета и запаха, 78 % воздуха. Молекула N≡N очень прочная (945 кДж/моль), поэтому азот химически инертен.

Химические свойства азота:

N₂ + 3H₂ ⇄ 2NH₃ (кат. Fe, t°)
N₂ + O₂ ⇄ 2NO (при очень высокой t°)
N₂ + 6Li → 2Li₃N (нитрид лития)

Степени окисления: от −3 до +5.

Получение: из жидкого воздуха (фракционная перегонка).

Применение: инертная среда (сварка, хранение продуктов), сырьё для синтеза аммиака, жидкий азот — хладагент.

Пример
Задание. Почему азот химически инертен?
Решение. Молекула N₂ содержит тройную связь с очень высокой энергией. Для её разрыва нужны высокие t°, давление, катализатор.
Задача

§10 Аммиак. Соли аммония

NH₃ — газ с резким запахом, легче воздуха, очень хорошо растворим в воде. Строение — тригональная пирамида.

Свойства аммиака:

NH₃ + H₂O ⇄ NH₄OH ⇄ NH₄⁺ + OH⁻ (щелочная среда)
NH₃ + HCl → NH₄Cl
2NH₃ + H₂SO₄ → (NH₄)₂SO₄
4NH₃ + 3O₂ → 2N₂ + 6H₂O (без кат.)
4NH₃ + 5O₂ → 4NO + 6H₂O (кат. Pt)
Соли аммония Соли, содержащие катион NH₄⁺. Образуются при взаимодействии аммиака с кислотами.
Примеры: NH₄Cl (нашатырь), (NH₄)₂SO₄, NH₄NO₃ (аммиачная селитра).

Свойства солей аммония:

NH₄Cl → NH₄⁺ + Cl⁻ (диссоциация)
NH₄Cl + NaOH → NaCl + NH₃↑ + H₂O (качественная реакция на NH₄⁺)
NH₄Cl → NH₃↑ + HCl↑ (при t°)
NH₄NO₃ → N₂O↑ + 2H₂O (при t°)

Применение: NH₄NO₃ и (NH₄)₂SO₄ — удобрения; NH₄Cl — паяльная кислота, батарейки; NH₄HCO₃ — разрыхлитель.

Пример
Задание. Как отличить соль аммония?
Решение. Добавить NaOH и нагреть: выделяется NH₃ (запах, синеет влажную лакмусовую бумажку). NH₄Cl + NaOH → NaCl + NH₃↑ + H₂O.

§11 Получение аммиака и изучение его свойств

Лабораторный способ: действие щёлочи на соль аммония при нагревании:

2NH₄Cl + Ca(OH)₂ → CaCl₂ + 2NH₃↑ + 2H₂O
NH₄Cl + NaOH → NaCl + NH₃↑ + H₂O (при t°)

Собирают NH₃ в перевёрнутую вверх дном пробирку, потому что NH₃ легче воздуха.

Промышленный способ (синтез Габера):

N₂ + 3H₂ ⇄ 2NH₃ + Q (кат. Fe, 400–500 °C, 200–1000 атм)

Лабораторная работа:

  1. NH₄Cl + Ca(OH)₂ → нагреть → выделяется NH₃.
  2. Собрать в перевёрнутую пробирку.
  3. Опустить в воду с фенолфталеином — вода втянется, станет малиновой (щёлочная среда).
  4. Палочка с HCl → белые клубы дыма NH₄Cl.

Признаки: запах NH₃, малиновый фенолфталеин, белый дым с HCl.

⚠ ТБ: NH₃ токсичен, работать в вытяжном шкафу.

Пример
Задание. Как собрать NH₃ в лаборатории?
Решение. NH₃ легче воздуха (M = 17 < 29), поэтому собирают в перевёрнутую вверх дном пробирку.

§12 Кислородные соединения азота

Азот образует оксиды от +1 до +5. Кислотные — N₂O₃ и N₂O₅. Несолеобразующие — N₂O и NO.

§13 Фосфор и его соединения

Фосфор P — элемент VA. В природе — только в виде соединений: Ca₃(PO₄)₂ (фосфорит), апатит.

Аллотропные модификации:

  • Белый P₄ — ядовит, светится, самовоспламеняется.
  • Красный Pₙ — не ядовит, устойчив на воздухе.
  • Чёрный Pₙ — похож на графит.

Химические свойства:

4P + 5O₂ → 2P₂O₅ (избыток O₂)
4P + 3O₂ → 2P₂O₃ (недостаток O₂)
2P + 3Cl₂ → 2PCl₃
3Ca + 2P → Ca₃P₂ (фосфид кальция)

P₂O₅ + 3H₂O → 2H₃PO₄ — фосфорная кислота, трёхосновная, средней силы.

Соли H₃PO₄: фосфаты (Na₃PO₄, Ca₃(PO₄)₂), гидрофосфаты (Na₂HPO₄), дигидрофосфаты (NaH₂PO₄).

Na₃PO₄ + 3AgNO₃ → Ag₃PO₄↓ (жёлтый) + 3NaNO₃

Применение: спички, H₃PO₄ (удобрения, E338), фосфорные удобрения (Ca(H₂PO₄)₂, CaHPO₄).

§15 Кислородные соединения углерода

2CO + O₂ → 2CO₂
Fe₂O₃ + 3CO → 2Fe + 3CO₂ (восстановитель в металлургии)

CO₂ (углекислый газ, +4) — бесцветный, тяжелее воздуха, не поддерживает горение.

CO₂ + H₂O ⇄ H₂CO₃ (угольная кислота)
CO₂ + Ca(OH)₂ → CaCO₃↓ + H₂O (помутнение известковой воды)

§16 Получение углекислого газа. Качественная реакция на карбонат-ионы

Лабораторный способ получения CO₂:

CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑
Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑

Промышленный способ:

CaCO₃ → CaO + CO₂↑ (при t° ≈ 1000 °C)

Собирают CO₂ в пробирку, поставленную вверх дном (CO₂ тяжелее воздуха).

Качественная реакция на CO₃²⁻ Действие сильной кислоты — вскипание (выделение CO₂), который мутнеет известковую воду:
1) Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑
2) Ca(OH)₂ + CO₂ → CaCO₃↓ + H₂O

Лабораторная работа:

  1. Мел + HCl → вскипание.
  2. Собрать газ в пробирку вверх дном.
  3. Пропустить через известковую воду → помутнение (CaCO₃).
  4. При избытке CO₂ помутнение исчезает: CaCO₃ + CO₂ + H₂O → Ca(HCO₃)₂.

Устранение временной жёсткости воды: Ca(HCO₃)₂ → CaCO₃↓ + H₂O + CO₂↑ (при кипячении).

Пример
Задание. Как доказать наличие карбоната натрия?
Решение. Прилить HCl — вскипание (CO₂). Пропустить газ через известковую воду — помутнение. Это доказывает наличие CO₃²⁻.

§17 Углеводороды

Углеводороды — органические соединения из C и H. Делятся на алканы, алкены, алкины, арены.

Алканы — CₙH₂ₙ₊₂ (метан CH₄, этан C₂H₆, пропан C₃H₈, бутан C₄H₁₀).

CH₄ + 2O₂ → CO₂ + 2H₂O (горение)
CH₄ + Cl₂ → CH₃Cl + HCl (замещение, на свету)

Алкены — CₙH₂ₙ (этилен C₂H₄). Содержат двойную связь.

C₂H₄ + 3O₂ → 2CO₂ + 2H₂O
C₂H₄ + Br₂ → C₂H₄Br₂ (присоединение, обесцвечивание бромной воды)
nC₂H₄ → (−CH₂−CH₂−)ₙ (полиэтилен)

Алкины — CₙH₂ₙ₋₂ (ацетилен C₂H₂). Содержат тройную связь.

2C₂H₂ + 5O₂ → 4CO₂ + 2H₂O (t° = 3000 °C)

Арены — содержат бензольное кольцо (бензол C₆H₆).

Применение: метан — топливо (природный газ); этилен — полиэтилен; ацетилен — сварка; бензол — красители, лекарства.

Пример
Задание. Напишите: горение метана, гидратация этилена, полимеризация этилена.
Решение. 1) CH₄ + 2O₂ → CO₂ + 2H₂O; 2) C₂H₄ + H₂O → C₂H₅OH; 3) nC₂H₄ → (−CH₂−CH₂−)ₙ.

§18 Кислородсодержащие органические соединения

Спирты содержат гидроксильную группу −OH.

  • Метанол CH₃OH — ядовит.
  • Этанол C₂H₅OH — винный спирт.
  • Глицерин C₃H₈O₃ — трёхатомный спирт.
C₂H₅OH + 3O₂ → 2CO₂ + 3H₂O (горение)
2C₂H₅OH + 2Na → 2C₂H₅ONa + H₂↑

Карбоновые кислоты содержат группу −COOH.

  • Муравьиная HCOOH — самая сильная из органических.
  • Уксусная CH₃COOH — слабая, в уксусе 6–9 %.
  • Лимонная C₆H₈O₇ — в цитрусах.
CH₃COOH ⇄ CH₃COO⁻ + H⁺
CH₃COOH + NaOH → CH₃COONa + H₂O
2CH₃COOH + Mg → (CH₃COO)₂Mg + H₂↑

CH₃CHO + Ag₂O → CH₃COOH + 2Ag↓ (серебряное зеркало)

Углеводы:

  • Глюкоза C₆H₁₂O₆ — моносахарид.
  • Сахароза C₁₂H₂₂O₁₁ — дисахарид.
  • Крахмал (C₆H₁₀O₅)ₙ — полисахарид (в картофеле).
  • Целлюлоза (C₆H₁₀O₅)ₙ — полисахарид (древесина, хлопок).

Качественная реакция на крахмал — синее окрашивание с иодом.

Применение: этанол — медицина, топливо; уксусная кислота — консервирование; глюкоза — питательные растворы.

§19 Кремний и его соединения. Силикатная промышленность

Кремний Si — 2-й по распространённости в земной коре (27 %). Атомная решётка, тёмно-серый, с металлическим блеском.

Химические свойства:

Si + O₂ → SiO₂
Si + 2Cl₂ → SiCl₄
Si + 2NaOH + H₂O → Na₂SiO₃ + 2H₂↑
2Mg + Si → Mg₂Si

SiO₂ — кварц, песок, кремнезём. Атомная решётка, очень тугоплавкий. Кислотный оксид.

SiO₂ + 2NaOH → Na₂SiO₃ + H₂O
SiO₂ + CaO → CaSiO₃

💡 SiO₂ не реагирует с водой.

Кремниевая кислота H₂SiO₃ — слабая, нерастворимая.

Na₂SiO₃ + 2HCl → H₂SiO₃↓ + 2NaCl
Силикатная промышленность Отрасль, производящая стекло, керамику, цемент на основе соединений кремния.

Стекло: SiO₂ + Na₂CO₃ + CaCO₃ при t° → силикаты. Виды: оконное, кварцевое, хрустальное, оптическое, цветное.

Керамика: глины, фарфор, фаянс.

Цемент: обжиг глины и известняка. Цемент + вода + песок + щебень = бетон.

Применение кремния: полупроводники, электроника, солнечные батареи, сплавы.

Пример
Задание. Напишите: Si + O₂, SiO₂ + NaOH, Na₂SiO₃ + HCl.
Решение. 1) Si + O₂ → SiO₂; 2) SiO₂ + 2NaOH → Na₂SiO₃ + H₂O; 3) Na₂SiO₃ + 2HCl → H₂SiO₃↓ + 2NaCl.

  1. N₂ + 3H₂ ⇄ 2NH₃ (Fe, 500 °C, 300 атм)
  2. 4NH₃ + 5O₂ → 4NO + 6H₂O (кат. Pt)
  3. 2NO + O₂ → 2NO₂
  4. 4NO₂ + O₂ + 2H₂O → 4HNO₃

4. Аммиак NH₃:

N₂ + 3H₂ ⇄ 2NH₃ + Q (Fe, 400–500 °C, 200–1000 атм)

5. Фосфорная кислота H₃PO₄:

P₂O₅ + 3H₂O → 2H₃PO₄
Ca₃(PO₄)₂ + 3H₂SO₄ → 3CaSO₄ + 2H₃PO₄

6. Аммиачные удобрения:

NH₃ + HNO₃ → NH₄NO₃
2NH₃ + H₂SO₄ → (NH₄)₂SO₄
2NH₃ + CO₂ → CO(NH₂)₂ + H₂O

Значение: H₂SO₄ — «хлеб химической промышленности»; азотные удобрения повышают урожайность; аммиак — сырьё для удобрений и HNO₃.

§1 Общая характеристика металлов

Металлы — элементы, атомы которых отдают электроны, образуя положительные ионы. Около 90 из 118 элементов — металлы.

Металлы Химические элементы, атомы которых имеют на внешнем уровне 1–3 электрона и легко их отдают. У металлов большие радиусы и низкая электроотрицательность.

Положение в ПСХЭ: элементы побочных подгрупп, а также IA, IIA, IIIA (кроме B).

Строение: 1–3 электрона на внешнем уровне, большие радиусы, низкая ЭО, легко отдают электроны.

Металлическая связь Связь, при которой положительные ионы металла удерживаются в узлах решётки свободными (обобществлёнными) электронами — «электронным газом».

Физические свойства:

  • Металлический блеск — отражение света свободными электронами.
  • Электро- и теплопроводность — свободные электроны.
  • Ковкость и пластичность — слои ионов легко смещаются.
  • Твёрдость: от мягких (Na, K) до твёрдых (Cr, W).
  • Плотность: лёгкие (Li, Na) и тяжёлые (Pb, Os).
  • t° пл.: легкоплавкие (Hg — жидкость) и тугоплавкие (W — 3410 °C).

§2 Химические свойства металлов

Все металлы — восстановители, но активность разная.

Физические свойства: серебристо-белые мягкие, лёгкие, низкие t° пл., хранят под керосином.

2Na + 2H₂O → 2NaOH + H₂↑

§4 Общая характеристика элементов IIA группы — щёлочноземельные металлы

§5 Жёсткость воды и способы её устранения
Жёсткость воды Свойство воды, связанное с содержанием в ней растворимых солей кальция и магния (Ca²⁺, Mg²⁺).

Виды:

  • Временная (карбонатная) — гидрокарбонатами Ca(HCO₃)₂ и Mg(HCO₃)₂. Устраняется кипячением:
    Ca(HCO₃)₂ → CaCO₃↓ + H₂O + CO₂↑
  • Постоянная (некарбонатная) — сульфатами и хлоридами (CaSO₄, MgSO₄, CaCl₂). Кипячением не устраняется.
  • Общая = временная + постоянная.

Проблемы жёсткой воды: накипь на стенках котлов, плохое мыло, износ оборудования.

Способы устранения:

1) Кипячение (только временной)
2) Сода: CaCl₂ + Na₂CO₃ → CaCO₃↓ + 2NaCl
3) Известь: Ca(HCO₃)₂ + Ca(OH)₂ → 2CaCO₃↓ + 2H₂O
4) Ионообменные смолы
5) Дистилляция (полное умягчение)

Значение: умягчённая вода нужна в промышленности (котлы, теплообменники), в быту, в медицине.

Пример
Задание. Как устранить временную жёсткость?
Решение. Кипячением: Ca(HCO₃)₂ → CaCO₃↓ + H₂O + CO₂↑. Или добавлением Ca(OH)₂: Ca(HCO₃)₂ + Ca(OH)₂ → 2CaCO₃↓ + 2H₂O.

§6 Алюминий и его соединения

Al — элемент IIIA, самый распространённый металл в земной коре (8,8 %). На внешнем уровне 3 электрона.

Физические свойства: серебристо-белый лёгкий (ρ = 2,7 г/см³), пластичный, хорошо проводит ток и тепло, t° пл. = 660 °C. На воздухе покрыт защитной плёнкой Al₂O₃.

Химические свойства:

4Al + 3O₂ → 2Al₂O₃
2Al + 6HCl → 2AlCl₃ + 3H₂↑
2Al + 2NaOH + 2H₂O → 2NaAlO₂ + 3H₂↑ (амфотерность)
2Al + Fe₂O₃ → Al₂O₃ + 2Fe (алюминотермия)

С конц. HNO₃ и H₂SO₄ на холоде пассивируется.

Амфотерные соединения:

Al₂O₃ + 6HCl → 2AlCl₃ + 3H₂O
Al₂O₃ + 2NaOH → 2NaAlO₂ + H₂O
Al(OH)₃ + 3HCl → AlCl₃ + 3H₂O

Качественная реакция на Al³⁺: с NaOH образуется белый студенистый осадок Al(OH)₃, который растворяется в избытке щёлочи.

Применение: самолётостроение, автомобилестроение, электротехника, посуда, фольга, алюминотермия.

Пример

Решение. 1) 4Al + 3O₂ → 2Al₂O₃; 2) 2Al + 6HCl → 2AlCl₃ + 3H₂↑; 3) Al(OH)₃ + NaOH → Na[Al(OH)₄].

§7 Железо и его соединения

Fe — элемент VIIIB, второй по распространённости металл в земной коре (4,65 %). Степени окисления +2, +3.

Физические свойства: серебристо-белый, плотный (ρ = 7,87), тугоплавкий (1539 °C), ферромагнитен.

Химические свойства:

3Fe + 2O₂ → Fe₃O₄ (окалина)
4Fe + 3O₂ → 2Fe₂O₃ (ржавчина, при влажности)
2Fe + 3Cl₂ → 2FeCl₃
Fe + 2HCl → FeCl₂ + H₂↑
Fe + CuSO₄ → FeSO₄ + Cu↓
3Fe + 4H₂O → Fe₃O₄ + 4H₂↑

С конц. HNO₃ и H₂SO₄ на холоде пассивируется.

Соединения Fe(II): FeO (чёрный), Fe(OH)₂ (зеленоватый), FeSO₄·7H₂O (железный купорос).

Соединения Fe(III): Fe₂O₃ (красный железняк), Fe(OH)₃ (бурый), FeCl₃.

Качественные реакции:

  • Fe²⁺: с K₃[Fe(CN)₆] (красная кровяная соль) → синий осадок.
  • Fe³⁺: с K₄[Fe(CN)₆] (жёлтая кровяная соль) → синий осадок берлинской лазури.
  • Fe³⁺: с KSCN → кроваво-красный цвет.

Применение: чёрная металлургия (сталь, чугун), машиностроение, Fe₂O₃ — пигмент, FeSO₄ — медицина.

Пример
Задание. Напишите: Fe + HCl, Fe + Cl₂, Fe + CuSO₄, Fe(OH)₃ → t°.
Решение. 1) Fe + 2HCl → FeCl₂ + H₂↑; 2) 2Fe + 3Cl₂ → 2FeCl₃; 3) Fe + CuSO₄ → FeSO₄ + Cu↓; 4) 2Fe(OH)₃ → Fe₂O₃ + 3H₂O.

§8 Коррозия металлов и способы защиты от неё
Коррозия Самопроизвольное разрушение металлов и сплавов под действием окружающей среды (кислорода, воды, кислот, солей).

Виды:

  • Химическая — в сухих газах или неэлектролитах (при высоких t°).
  • Электрохимическая — в присутствии электролита (влажный воздух, растворы солей). Более частая и опасная.

Электрохимическая коррозия:

Fe → Fe²⁺ + 2e⁻ (анод, окисление)
O₂ + 2H₂O + 4e⁻ → 4OH⁻ (катод, восстановление)
4Fe(OH)₂ + O₂ + 2H₂O → 4Fe(OH)₃ → Fe₂O₃·nH₂O (ржавчина)

Факторы, ускоряющие коррозию: влажность, соли, кислая среда, контакт разных металлов, механические нагрузки.

Способы защиты:

  • Покрытия: лаки, краски, эмали; металлические — хромирование, никелирование, цинкование, лужение.
  • Легирование: добавление Cr, Ni, Ti (нержавеющая сталь).
  • Протекторная защита: к защищаемой конструкции крепят более активный металл (Zn, Mg).
  • Изменение среды: ингибиторы, осушение воздуха.
  • Электрохимическая защита: подключение к источнику тока.
Пример
Задание. Почему оцинкованное железо не ржавеет даже при повреждении покрытия?
Решение. Цинк активнее железа: при повреждении он окисляется первым, защищая железо (протекторная защита). Олово, наоборот, менее активно — при повреждении корродировать начнёт железо.

§9 Металлы в природе. Понятие о металлургии

Формы нахождения металлов:

  • Самородные: Au, Ag, Pt (реже Cu, Hg).
  • Оксиды и гидроксиды: Fe₂O₃, Fe₃O₄, Al₂O₃, MnO₂.
  • Сульфиды: FeS₂, PbS, ZnS, HgS, CuFeS₂.
  • Карбонаты: CaCO₃, MgCO₃, FeCO₃.
  • Сульфаты: CaSO₄·2H₂O, BaSO₄.
  • Хлориды: NaCl, KCl, MgCl₂.
  • Силикаты: основа земной коры.
  • Фосфаты: Ca₃(PO₄)₂.
Металлургия Наука и отрасль промышленности, занимающаяся получением металлов из природного сырья.

Способы получения металлов:

1. Пирометаллургия — восстановление при высоких t°:

Fe₂O₃ + 3C → 2Fe + 3CO↑
Fe₂O₃ + 3CO → 2Fe + 3CO₂↑
WO₃ + 3H₂ → W + 3H₂O
2Al + Fe₂O₃ → Al₂O₃ + 2Fe (алюминотермия)

2. Гидрометаллургия — из растворов:

CuO + H₂SO₄ → CuSO₄ + H₂O
CuSO₄ + Fe → FeSO₄ + Cu↓

3. Электрометаллургия — электролиз расплавов или растворов:

2NaCl → 2Na + Cl₂↑ (электролиз расплава)
2Al₂O₃ → 4Al + 3O₂↑ (в криолите)

Значение: чёрная металлургия — сталь и чугун, цветная — Cu, Al, Zn, Pb, Ni. Основа машиностроения, строительства, энергетики.

Проблемы: энергоёмкость, загрязнение среды, истощение руд. Пути решения: переработка отходов, безотходные технологии, очистка выбросов.

Пример
Задание. Как получить железо из Fe₂O₃ тремя способами?
Решение. 1) Fe₂O₃ + 3C → 2Fe + 3CO↑; 2) Fe₂O₃ + 3CO → 2Fe + 3CO₂↑; 3) Fe₂O₃ + 2Al → Al₂O₃ + 2Fe.

§2 Охрана окружающей среды от химического загрязнения

Хозяйственная деятельность человека загрязняет атмосферу, гидросферу и литосферу.

Основные источники загрязнения: промышленность (SO₂, NO₂, CO, пыль, тяжёлые металлы), транспорт (выхлопные газы), сельское хозяйство (пестициды, удобрения), энергетика, бытовые отходы.

ВидЗагрязнителиПоследствия
АтмосферноеSO₂, NO₂, CO, фреоныКислотные дожди, смог, парниковый эффект
ВодноеНефть, металлы, ПАВГибель рыбы, отравление воды
ПочвенноеПестициды, металлыСнижение плодородия
РадиоактивноеРадиоактивные отходыОблучение, мутации

Экологические проблемы: парниковый эффект (CO₂, CH₄, N₂O), кислотные дожди (SO₂, NO₂ → H₂SO₄, HNO₃), разрушение озонового слоя (фреоны), загрязнение Мирового океана, накопление отходов.

Меры охраны:

  • Технологические: безотходные производства, очистка выбросов и стоков, возобновляемая энергия, переработка.
  • Правовые: законы, штрафы, заповедники.
  • Воспитательные: экологическое образование, раздельный сбор.

Химия в защите природы: катализаторы для нейтрализации выбросов, биоразлагаемые полимеры, очистка воды и воздуха, мониторинг загрязнений.

Пример
Задание. Какие реакции вызывают кислотные дожди?
Решение. 1) S + O₂ → SO₂; N₂ + O₂ → 2NO. 2) 2SO₂ + O₂ → 2SO₃; 2NO + O₂ → 2NO₂. 3) SO₃ + H₂O → H₂SO₄; 3NO₂ + H₂O → 2HNO₃ + NO. Кислоты выпадают с дождём.

§2 Химические реакции

1. Типы по числу веществ:

  • Соединения: A + B → AB. Пример: 2H₂ + O₂ → 2H₂O.
  • Разложения: AB → A + B. Пример: 2H₂O₂ → 2H₂O + O₂↑.
  • Замещения: A + BC → AC + B. Пример: Fe + CuSO₄ → FeSO₄ + Cu↓.
  • Обмена: AB + CD → AD + CB. Пример: NaOH + HCl → NaCl + H₂O.

2. Правило Бертолле: реакции обмена идут до конца, если образуется осадок, газ или вода.

3. ОВР:

  • Окисление — отдача электронов.
  • Восстановление — принятие электронов.
  • Окислитель — принимает электроны.
  • Восстановитель — отдаёт электроны.

4. Электролитическая диссоциация:

  • Кислоты → H⁺ + кислотный остаток.
  • Основания → Me + OH⁻.
  • Соли → Me + кислотный остаток.

5. Скорость: зависит от природы, концентрации, t°, площади, катализатора, давления. Правило Вант-Гоффа: повышение t° на 10 °C ускоряет в 2–4 раза.

Пример
Задание. Определите тип: Zn + 2HCl → ZnCl₂ + H₂↑.
Решение. Замещение; экзотермическая; необратимая; ОВР (Zn⁰ → Zn²⁺, H⁺ → H⁰).
§3 Основы неорганической химии

1. Основные оксиды + H₂O → основание (для щелочных Ме); + кислота → соль + вода.

2. Кислотные оксиды + H₂O → кислота; + основание → соль + вода.

3. Амфотерные: реагируют и с кислотами, и со щелочами.

Свойства кислот:

  • + металл до H₂ → соль + H₂↑.
  • + основной оксид → соль + H₂O.
  • + основание → соль + H₂O (нейтрализация).
  • + соль → новая соль + новая кислота (если осадок или газ).

Свойства оснований:

  • + кислота → соль + H₂O.
  • + кислотный оксид → соль + H₂O.
  • + соль → новая соль + новое основание (если осадок).
  • Нерастворимые: разлагаются → оксид + H₂O.

Свойства солей:

  • + металл (более активный) → новая соль + металл.
  • + кислота → новая соль + новая кислота.
  • + щёлочь → новая соль + новое основание (если осадок/газ).
  • + соль → две новые соли (если осадок).

Генетическая связь:

Ме → Основный оксид → Основание → Соль
Неметалл → Кислотный оксид → Кислота → Соль

Гидролиз: сильная + сильное → pH = 7; слабая + сильное → pH > 7; сильная + слабое → pH < 7; слабая + слабое → зависит.

Пример
Задание. Осуществите цепочку: Cu → CuO → CuSO₄ → Cu(OH)₂ → CuO.
Решение. 1) 2Cu + O₂ → 2CuO; 2) CuO + H₂SO₄ → CuSO₄ + H₂O; 3) CuSO₄ + 2NaOH → Cu(OH)₂↓ + Na₂SO₄; 4) Cu(OH)₂ → CuO + H₂O.
